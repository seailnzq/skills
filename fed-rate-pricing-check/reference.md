# fed-rate-pricing-check 参考手册

## 一、四级降级链详细操作

### 第①级：WebSearch（首选）

搜索词范式（按需组合）：

- `CME FedWatch 美联储 {月份} 加息/降息 概率 定价`
- `fed funds futures implied rate terminal {年份} after FOMC {月份}`
- `会后 累计加息 幅度 期货 美联储 {日期}`
- `{年份}年 首次降息 推迟 定价 期货 概率 交易员`
- 英文补充：`Fed rate odds {Month} FOMC futures pricing`

优先命中目标：**华泰宏观会后点评**（一个源同时含 FedWatch 概率、期货累计隐含加息幅度、2Y/10Y 收益率快照三组数字）。其次是同花顺（10jqka）快讯、laohu8、新浪财经、第一财经、中华网。

### 第②级：WebFetch 可达镜像

**已验证可达**（2026-09 实测）：

| 站点 | 说明 |
|---|---|
| `news.10jqka.com.cn` | 同花顺快讯，含独立概率口径，可与 FedWatch 数字互证 |

WebFetch 提取 prompt 范式：

> 提取会后市场对美联储利率路径的定价数字：(1) FedWatch 对未来两次会议的加息/降息概率；(2) 联邦基金期货隐含的到年底与到次年底/次年中的累计加息（或降息）幅度，及较会前的变动；(3) 隐含利率水平、隐含终端利率、首次降息时点定价；(4) 美债 2Y/10Y/30Y 会后读数与变动；(5) 美元指数、美股；(6) 文章发布日期。逐条列出数字+日期+口径。若正文为长图无法提取请明确说明。

## 二、口径术语表

| 术语 | 含义与换算 |
|---|---|
| FedWatch 概率 | CME 按联邦基金期货结算价推的会议加息/降息概率；报道转述时注明来源与时点 |
| 累计隐含加息幅度 | 期货隐含的到某时点相对当前目标区间的累计 bp 数（如 57bp、106bp）；÷25 ≈ 会议次数 |
| [推算] 标注 | 累计 bp → 具体利率区间的换算（锚 = 当前区间中值），例：中值 3.875% + 57bp ≈ 4.45%（4.25-4.50%） |
| 点阵图中位数 | SEP 官员预测中值；注意同时看点分布——鹰派翼（落在更鹰点的官员人数与落点）才是尾部风险 |
| 金融机构预测中位数 | SEP 中机构/经济学家预测栏，常与官员中位数分歧（如机构预期次年降息而官员中位数持平） |
| 时点口径 | 凌晨快照（会后数小时）vs 美股收盘；差 1-6bp 属常态，多源幅度不一致时定性为时点差异，**不当数据冲突** |

## 三、回写模板

### 月度利率与通胀跟踪报告 — FOMC 检验块行格式

```
| 决议 | {加息/降息/不动}{幅度}，区间 {X-Y%}；SEP 中值 {路径}；{记者会取向一句话} | {日期} |
| 当晚市场 | 道/标/纳涨跌；2Y {读数}{变动}、10Y {读数}{变动}；美元{变动}；金{变动}（单一来源则标注） | {收盘/快照时点} |
| 会后定价 | {月份}概率 {X}%；到{年底}累计加息 {bp}（较会前 {±bp}）、到{次年时点}累计 {bp}（{±bp}）；四方排序：{期货}＞{点阵图}＞{机构} | {时点口径}（来源） |
```

块后附：`**[待核实项已清] ...**`（定性说明）或 `**[待核实]** ...`（新挂单项）。

### log.md 追加条目格式

```
- 补录（{日期}追问核查会后期货定价）：{来源}{时点}——{关键概率}、到{时点}累计 {bp}（{±bp}）→ 判定"{充分/超额/不足定价 + 一句话方向}"，写入 [[synthesis/月度利率与通胀跟踪报告]] FOMC 检验块；{待核实项变动说明}
```

同轮更新 index 计数与"遗留未核实项"列表。

## 四、操作硬规则

1. **Edit 前同轮 Read**：目标文件（含 log.md）在本次工具调用轮内必须先 Read 再 Edit，上轮读过报 "File has not been read yet"。
2. **先改页、后提交、再答复**：回写完成并 push 成功（`git status --short` 为空）后才向用户交付结论；结论中每个数字须在页面有落点。
3. **两源互证**：核心概率/幅度数字尽量找两个独立口径互证（例：FedWatch 12 月 88.7% vs 同花顺"年底前再加息 25bp 约 90%"）。
4. **缺项显式说明**：收集项清单中拿不到的项（如 2027 腿无硬数字），在答复与页面中写明，不静默略过。
5. **仓库预检**：push 前若遇远端同步冲突，按 `wiki-research-sync` 的 vault backup 冲突规程（按时间序保留双方）处理。
