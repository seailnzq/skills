# 美联储利率路径定价核查

## 适用与不适用

**适用**：FOMC 决议后的市场定价核查、"是否已定价"类追问、月度利率跟踪的 FOMC 检验环节、点阵图/期货/机构预期对照。

**不适用（边界）**：
- 建新综合页入库 wiki → 用 `wiki-research-sync`
- 中文卖方研报/公众号当日采集镜像 → 用 `wechat-report-mirror-fetch`
- 个股行情/持仓 → 用 `a-stock-realtime`

本技能默认回写目标为 `C:\Users\l17405\github-repos\wiki-knowledge\wiki\synthesis\月度利率与通胀跟踪报告.md` 的 FOMC 检验块；若用户指定其他页面，流程不变、目标替换。

## 步骤

### 1. 决议事实基线

先锁定决议本身，后续所有对照以此为锚：

- 利率决议：加息/降息/按兵不动、幅度、目标区间、投票情况
- SEP 点阵图：2026/2027/2028 各年中值路径 + 点分布（鹰派翼人数与落点）
- 通胀与增长预测调整
- 记者会核心表态（尤其是前瞻指引取向）
- 每个数字带日期与口径标注

来源优先：美联储官网原始文件 > WebSearch 会后报道 > 卖方点评转述。

### 2. 会后期货定价采集（四级降级链）

**收集项清单**（缺项在结论中显式说明）：
- 未来 2 次会议的加息/降息概率（FedWatch 或报道转述）
- 到当年底、到次年底/次年中的期货累计隐含加息（或降息）幅度，及较会前变动
- 隐含利率水平换算、隐含终端利率
- 首次降息时点定价
- 美债 2Y/10Y/30Y、美元指数、美股会后读数

### 3. 四方对照判定

按固定顺序排列并输出排序关系：

1. **期货定价**（最鹰/最鸽的市场边）
2. **点阵图中位数**（含鹰派翼分布：落在加息/降息点的官员人数）
3. **金融机构预测中位数**（SEP 中"机构/经济学家预测"栏）
4. **主要卖方观点**（会后点评的独立判断，如"降息窗口后移"）

判定三分类：
- **充分定价**：期货与点阵图/共识一致
- **超额定价**：期货比点阵图中位数更鹰（或更鸽）——此时风险在"定价回吐"一侧而非"事件落地"一侧
- **不足定价**：期货落后于点阵图指引

关键区分：**"事件是否被定价"与"节奏是否被定价"是两回事**（例：12 月加息事件已定价 90%，但 10 月只有 50%——若 10+12 连加 50bp，短端还有一档未定价）。结论必须拆开说。

### 4. 口径校验与标注规范

- **盘中快照 vs 收盘**：不同来源 2Y/10Y 变动幅度不一致时（如华泰凌晨快照 +13bp vs 镜像收盘 +7bp），定性为时点口径差异，**不当数据冲突处理**，并在页面 [待核实] 标注中清零或注明
- **换算标 [推算]**：期货"累计隐含加息幅度"（bp）→ 具体利率区间，属推算，标 [推算] 并给出锚（当前中值）
- **单一来源标 [待核实]**：如伦敦金读数、细节性事实，进页面待核实清单
- **数据时点显式化**：写明"北京时间 X 日凌晨 4:00 快照"还是"X 日收盘"
- 换算锚：从当前联邦基金目标区间中值起算，累计 bp ÷ 25 ≈ 会议次数

## 输出格式

**对话内答复范式**：
1. 第一句直接回答（已/未定价，充分/超额）
2. 数据块：截至 X 时点的概率与累计幅度，标 [推算]/[待核实]
3. 四方排序一句话
4. 拆分"事件定价 vs 节奏定价"
5. 风险转移判读：超额定价时指出回吐触发条件（哪些数据降温会让市场吐回定价）
6. 口径与未核实声明

**回写检查**：结论中每个数字在页面上有落点；页面每条 [待核实] 的状态与结论一致；git push 后 `git status --short` 为空。
