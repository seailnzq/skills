# 微信研报镜像采集流水线

## Steps

1. **判定当日新收藏**：`ls -lt "WPSDrive/276687336/WPS云盘/应用/金山收藏助手/"`（路径按用户环境调整），找当天时间戳的新增条目。`.otl.wpsonline` 后缀 = 云指针，本地无正文，内容须从 Reportify 等线上渠道获取。
   - **先重列再判定**：该目录会随当天同步**陆续新增**（一次 `ls -lt` 判"无当日新增"不算数，尤其用户提示"还更新了几篇"时）。得出结论前至少重新 `ls -lt` 一次再核对时间戳，避免把当天稍晚同步进来的文章漏掉。
   - **回退分支（确认当日无新增）**：重新列目录仍无当天时间戳条目时，取最近 N 条收藏（默认 3，可按用户指定），并在输出开头**显式标注**"以下为会前/当日之前的旧收藏（收藏日期 X），不代表最新会后结论"。若用户目的明显是"会后解读"，须同时提示当日无新收藏，并在分析中区分会前观点与会后验证，勿把会前判断当作事后结论引用。

2. **Reportify 定位原文（仅限已登记频道的账号）**：
   - **有频道**：仅当文章属于"郭磊宏观茶座"（频道 ID = `S10740353838202886`）或其他已在本技能 reference 中登记 Reportify 频道 ID 的公众号时，WebFetch `reportify.cn/channels/<频道ID>/documents`，按标题/日期匹配目标文章；进入文章详情页（`reportify.cn/social-media/<文章ID>`）取"查看原文链接"，得到 mp.weixin.qq.com 直链。
   - **无频道/非郭磊账号**（如华创张瑜、兴证张启尧、中金、长江等）：**跳过本步**，不要猜测或复用郭磊的频道 ID；直接以"标题关键词 + 作者/团队名"进入 step 4 的镜像检索主路径（新浪财经、东方财富 finance.eastmoney、www.163、格隆汇、雪球、华尔街见闻、慧博、laohu8 等），微信 mp.weixin 直链仍直接跳过。

3. **取正文（按序降级，失败即切下一档，不重试同一来源）**：
   a. 直抓 mp.weixin.qq.com 直链；
   b. 被风控拦截（验证页/空正文）→ 改抓该页面 `js_content` 内链，或用 Reportify 文章页结构化摘要兜底；
   c. 纯长图类正文无法文本提取 → 明确标注"正文未获取"，只输出摘要层信息，禁止用摘要冒充全文。
   d. **超时即换源，不同源重试**：任一来源返回 `WebFetch timed out after 120000ms` 或 `fetch failed` 视为硬失败，立刻切下一个镜像源，**绝不重试同一 URL**。超时高发源：`news.qq.com`、观察者网(`guancha.cn`)、`163`、部分英文财经站(nextfin/morningstar/hibor wap)；更稳源：`laohu8.com`、东方财富(`finance.eastmoney`/`guba.eastmoney`/`caifuhao.eastmoney`)、同花顺(`news.10jqka.com.cn`)、新浪财经研报登记页(`stock.finance.sina.com.cn/.../vReport_Show/...`)。优先落到稳源。

4. **镜像并行提炼**：从标题提取关键词（如"出口""十五五""PMI"），按关键词分组派子代理并行检索镜像全文，补齐 Reportify/镜像摘要缺失的段落（环比、量价拆分、汇率分析、逐月展望等）。**派单时给子代理写明稳源优先序**：laohu8.com、东方财富(finance/guba/caifuhao.eastmoney)、同花顺(news.10jqka)、新浪财经研报登记页优先，网易(163)/搜狐/格隆汇/雪球/华尔街见闻作次选补漏（这些站超时高发，命中即换、不重试）。分支①（无频道账号跳过 step 2）时本步即全文主采集路径。镜像站点检索 URL 模板、稳定性分层与技巧见本技能目录下 reference.md。

5. **固定格式输出**：
   - 核心论点
   - 带日期数字的论据（每条数字须带对应统计期，如"8 月出口同比 +25.0%"）
   - 资产定价含义
   - 来源URL（原文 + 各镜像逐条列出）
   - 未核实项清单（取不到/推断的部分显式列出；无则写"无"）

6. **可选扩展 · 市场定价类采集口径**（当追问属"加息概率/期货隐含路径/收益率读数"这类而非纯研报正文时）：
   - 采集对象改取卖方**会后点评**（如华泰宏观、银河、广发陈嘉荔等当日/次晨发布的会后文），而非会前预判文——会前判断不得充当事后市场定价。
   - 提炼每条数字须带齐：概率（FedWatch/期货隐含）、bp 幅度、收益率/指数读数、**口径**（"累计隐含加息幅度"vs"利率区间"要区分，换算须标[推算]）、**时点**（盘中快照 vs 收盘；两者 1‑6bp 差异不是数据冲突）。
   - 单一来源读数（如某商品价格、某专项细节）计入未核实项。
   - 边界：完整的"决议事实→会后定价→四方对照→充分/超额/不足判定"核查流水线交由专用技能 `fed-rate-pricing-check`；本步只负责把采集到的定价数字按上述口径整理清楚。

7. **可选衔接 · 回写入库**：当用户目的是"分析学习入库"时，本流水线（含 step 6）的输出可直接作为 `wiki-research-sync` 的输入——建 paper/concept/synthesis 页、双向链接、更新 index/log、链接校验、commit+push，无需重复提炼；市场定价类结论优先回写库内"月度利率与通胀跟踪"类锚点页。

## Pitfalls

- mp.weixin.qq.com 直抓几乎必被风控拦截，不要反复重试，直接降级到 js_content / 镜像。
- Reportify 只有要点式结构化摘要，且常抹掉原文链接的完整参数——只作兜底与元数据源，不作全文来源。
- `.otl.wpsonline` 文件是云指针，本地读取只得指针元数据，不要当作损坏文件处理。
- 长图类正文（整篇为图片）无法文本提取，务必标注"正文未获取"。
- 同一日多篇文章时逐篇独立走完整流程，输出逐篇分节。
- 镜像站转载可能删节图表数据，与 Reportify 摘要冲突处记入未核实项。
- Reportify 频道 ID 与账号一一对应，郭磊频道的 ID 对其他公众号无效；未登记频道的账号不要猜测频道 ID，直接走标题关键词镜像。
- 回退取旧收藏时，文章发布日期 ≠ 会后结论；输出必须保留"收藏日期 vs 发布日期 vs 相关事件日期"的对照，防止会前观点被引用为会后验证。
- 金山收藏目录当天会陆续同步新文章，一次 `ls -lt` 判"无当日新增"不可直接定论；用户提示有更新时须重新列目录再判，否则漏掉稍晚同步进来的文章。
- 任一镜像站返回 `timed out after 120000ms`/`fetch failed` 与微信风控同级：立即换源、绝不重试同一 URL。news.qq.com/观察者网/163/部分英文财经站超时高发，laohu8、东财、同花顺、新浪研报登记页更稳。
- 市场定价数字必须区分**盘中快照 vs 收盘**两个口径：同一指标两者常有 1‑6bp 差异，属时点差异而非数据冲突，误判会制造假"未核实"。
- 市场定价类结论以**会后点评**为准，会前预判文（含"会议将如何"类）不得当作会后市场定价引用；换算成利率区间的部分标[推算]，单一来源读数入未核实项。

## Verification

- 输出含全部五要素，未核实项非空或显式写"无"。
- 每条数字论据可追溯到至少一个来源 URL。
- 镜像内容与 Reportify 摘要要点交叉核对，冲突已记入未核实项。
- 回退分支（无当日新收藏）的输出含"收藏日期 vs 发布日期 vs 相关事件日期"对照标注。
- 判定"当日无新增"前，确认已重新 `ls -lt` 再下结论（避免漏掉当天稍晚同步进来的文章）。
- 市场定价类（step 6）输出：每条数字带 概率/期货口径 + 时点（盘中快照 vs 收盘）+ 来源，换算项标[推算]，单一来源读数入未核实项。
