# Chapter 2: 信息、思维和组织（书页 34–74）

## Core Idea
"知道"就是可能性空间缩小——信息可以量化（比特），控制离不开信息；传递信息要匹配通道容量、对抗干扰（滤波），而组织就是联系方式的确定性。

## Frameworks Introduced
- **信息量 = 可能性空间缩小的比例，取以 2 为底的负对数（单位比特）**。好处：①几次获得的信息量可加总；②空间缩小信息量为正、不变为 0、扩大为负。
- **信息的传递 = "可能性空间缩小过程的传递"**：传递的不是物质或能量。三环节：信息源→通道→接受者。信号=信息在传递中的形式；通道=信源与接受者之间的联系。DNA→生化系统→遗传特征就是一条控制链。
- **信息的主观性**：信息只有在传递中才有意义；同一信息对不同接受者意义完全不同（华容道：同一股烟，曹操读出"无伏兵"，关羽读出"有伏兵"）。"切不可把经过人的头脑加工的、带有主观色彩的信息与所发生的客观事件混为一谈。"
- **通道容量**：一条通道单位时间可传递的最大信息量。三因素：①人控制通道的速度和能力；②通道可辨状态的数目；③信号对接受者的控制能力（信任/了解程度）。判定："选择通道容量不要太大也不要太小，最好等于你所要传递的信息量。"（琴只有一种弦→传不出音乐；几百种颜色的信号灯→司机晕）
- **干扰三分类**：控制干扰（人操作环节）、自然干扰/噪音（传递环节）、主观干扰（接受环节）。
- **滤波七法（去伪存真）**：
  1. **同一通道重复传递**——只对随机偶然干扰有效（重讲一遍、计算机验算）。
  2. **不同通道传递同一信息再对比**——对系统性干扰有效；各通道的**环节要尽量不同**（曾参杀人：三个报信人同样把"姓名↔人"弄错，等于同一条通道）。事件越重大，需越多的独立通道（核导弹双人制、高等生物双亲染色体互核）。
  3. **信息量守恒**——"信息在传输过程中只会不断减少，不会增加"；环节越多干扰越多，尽量靠近信息源（郑人买履：信稻草不信自己的脚）。
  4. **阻抗滤波**——找干扰与信号的本质差别，让干扰通不过（收音机选台、碘遇淀粉变蓝、感官只对"适宜刺激"开放）。
  5. **情调滤波**——让信息带上情调传递（丧鼓音色、焦急喊叫、骷髅标）。
  6. **反馈滤波**——用收到的有用信号反作用通道以抑制无用信号（"视而不见、听而不闻"）。
  7. **同步滤波**——信号与通道开关同步（气泡室快门只在气泡产生一瞬打开）。
- **信息的储存**：一切保存 = 双重变换 A→B→C（L_AB 与 L_BC）。三特点：①B 的可辨状态必须比 A 稳定（"把不稳定的可辨状态变换成一种稳定的可辨状态"——照片、化石；镜子不行因映像与实物同生同灭）；②B 通常只反映 A 的一个侧面（多一对应）；③必须知道对应关系 L_AB 与 L_BC 才能取用（"记"是 L_AB，"忆"是 L_BC）。
- **信息加工三形式**：逻辑思维（三段论="判断句的'是'指可能性空间的包含关系"，推理即"可能性空间怎样缩小是合理的"）、概率推理（条件概率分解代替直观）、自由联想（经共同部分迁移；**反模式：陷入封闭循环**——情绪反刍、失眠者"老围着几个念头打转转"）。
- **形象空间与概念空间的共轭**：推理常是"形象 N1 →(L) 概念 n1 →(逻辑 f) 概念 n2 →(L⁻¹) 形象 N2"——人每天千百万次在两个空间间做共轭变换。
- **信息和组织**：组织=事物间**联系方式的**可能性空间从大变小（三人排队的三道命令：任意走动→正三角形→以旗杆为中心→唯一点）。"一个系统组织程度的度量跟信息量是一致的"——系统必须获得信息才能组织起来。

## Key Concepts
- **生物反馈疗法**：人不能控制心跳血压，很大程度是没获得其活动情况的信息；仪器把心律血压变成可见信号=构成信息传递的新通道。
- **"只有获得目标的足够信息量，才能控制目标"**（纪昌学箭的真义：先练眼力=先攒信息量）。
- 知行统一：知=获得信息，行=实行控制。

## Mental Models
- **知道=缩小**：检验自己是否"知道"某事，就看它给你的可能性空间缩了多少。
- **通道匹配**：传不出去先查三因素——可辨状态够不够、操作速度够不够、对接受者的控制力够不够（鼓语比报纸先到非洲内陆）。
- **可靠性=通道多样性**：越重大的判断越要多条"环节互不相同"的通道互证。

## Anti-patterns
- 把主观加工过的信息当客观事实（哥廷根实验：40 份科学家报告仅 1 篇主要事实错误少于 20%，一半以上掺虚构）。
- 盲信"仪器越精密越好"：可辨状态增加但单位时间信息通过量反而下降。
- 破坏通道受控性（周幽王戏点烽火→真警报传不出）。
- 用重复传递对付系统性干扰；多通道互证但各通道环节雷同。
- 让联想陷入封闭循环不跳出。
- 只建 B 不懂 L_BC：存了一堆资料却取不出来。

## Worked Example
**地震预报的概率推理**（2.7）：某地统计资料——五级以上地震平均 3000 年一次；井水变枯平均 30 年一次；地震前 90% 井水变枯。问：井水变枯了，要地震的概率是 90% 吗？用条件概率分解：D/A = (D/B)·(B/C)·(C/A) = (90/100)×(1/3000)×(30/1) = 9/1000。即井水变枯时地震概率不足 1%——"这就得出比直观判断更正确的结论"。要点：把"共同出现"翻译成 A⊃D、B⊃D 的包含结构，用基数（1/3000、30/1）做惩罚因子，直觉里的"90%"只是 (D/B) 这一段。

## Key Takeaways
1. 信息量算负对数：缩小 1/10 = log₂10 比特；几次信息可加总。
2. 控制无效先查信息：是否获得了关于目标的足够信息量。
3. 通道容量匹配信息量，过大浪费且添干扰。
4. 按干扰类型选滤波法：随机→重复；系统→异通道对比；频率差异→阻抗；主观→情调；持续无用→反馈；间歇混入→同步。
5. 储存信息 = 变换成更稳定的状态，且必须知道对应关系才能取用。
6. 推理用条件概率分解，不用直观。
7. 思维陷入循环打转时，主动打破封闭回路。
