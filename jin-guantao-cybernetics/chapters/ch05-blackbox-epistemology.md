# Chapter 5: 黑箱认识论（书页 170–205）＋ 附录

## Core Idea
认识是主体与客体之间的反馈耦合："实践—理论—实践"就是负反馈调节；这个调节机器有五个可能失灵的部位——变量限制、清晰性缺失、速度不够、反馈过度、可判定条件不成立。

## Frameworks Introduced
- **黑箱与两组变量**：客体对主体的作用反映在输出中=**可观察变量**；主体对客体的作用反映在输入中=**可控制变量**。"系统和黑箱是两个等价的概念。"人的实践活动根本上都可表示为主体和客体之间的反馈耦合。
- **两种认识方法**：**不打开黑箱**（不动原有结构，从输入输出关系推理内部结构）与**打开黑箱**（直接观察控制内部——"打开黑箱在任何场合只是打开了黑箱的某一个层次"，黑箱一层套一层永不完结：性状→基因→染色体→DNA→遗传密码）。
- **模型（定义原文）**："根据黑箱外部的输入输出而提出的关于黑箱内部的情况的假定，在控制论中称为模型。"孟德尔从未见过基因，从豌豆性状推出"因子"——典型不打开黑箱。
- **不打开黑箱方法特别重要的三类系统**：①内部结构极复杂的特大系统（打开只能局部观察，不开反利整体考察）；②现有手段打不开的（地球内部）；③打开会严重干扰结构的（生物体、狗的视觉——巴甫洛夫靠唾液分泌这个输出判明狗是色盲、靠亮度分辨且比人敏感）。
- **认识论模式**：客观存在 A、主观认识 B、人 D、比较器 C；实践结果与理论预期结果的目标差驱动模型修改。"实践—理论—实践"反复循环=负反馈调节原理。但反馈调节逼近目标**有条件**——不满足时：长期停留在远离目标的错误稳态，或在目标附近左右摇摆振荡。
- **五个失效条件**（5.3–5.7 逐一展开）：
  1. **可观察/可控制变量的限制**：变量水平不动，理论只能在旧范围内被"检验"，循环一万次也不逼近真理——须先更新实践手段（范·赫尔蒙特柳树实验因不知 CO₂ 与光合作用而得出"树是水做的"；塞贝克因"电流"不可观察而错解地磁；吴健雄验证宇称不守恒靠超低温技术）。
  2. **理论的清晰性**："理论要给出一定的信息量。"与波普尔可证伪性一致。"明天有雨"可检验；"明天可能下雨也可能不下雨"信息量为零。**最犯忌的是模棱两可的理论**——"甚至还不如虽然完全不对但表述清晰的观点，因为后者无论如何是可以得到实践的检验的"。托勒密、盖伦、燃素说虽错但清晰，因而可被修正而通向真理；对照：中国古代数学不用符号不写中间步骤。
  3. **反馈速度 < 客体变化速度**：调节无效并振荡（楚军探水毕而山洪至，淹死数千人；计划经济电风扇"一放就乱一乱就收"；里查德森 6 小时天气预报败于运算速度）。对策：循环速度必须不低于客体变化速度（摩尔根选 10 天一代的果蝇而非一年一季的豌豆，开创遗传学新纪元）。
  4. **反馈过度**：每次修改都过头→认识从一种极端跳向另一种极端（导弹寻的偏左偏右打不下飞机；目的性震颤；光学三百年在微粒说—波动说间振荡）。
  5. **可判定条件不成立**："实践结果和理论结果之间的误差必须能够反映理论跟客观真理的接近程度"这个大前提可能失效——误差大未必错（薛定谔含相对论的第一个方程后来复活为克莱因—高登方程；哥白尼日心说算得并不比托勒密准），误差小未必对。此时"科学家经常像瞎子摸象一样来寻找真理……等于把鹰的眼睛蒙起来去抓兔子，反馈调节变成了一个随机控制"。
- **中间标准与范式**：可判定条件不成立时，人们同时使用一些**中间标准**（与库恩"范式"相关）：爱因斯坦因信仰真理统一性而不发表与能量守恒矛盾的"导场"理论；泡利凭中间标准预见中微子；普朗克只按眼前实验修改理论而两度倒退。范式不是最终标准，是"中间路标"。
- **规律=变量间的约束**；条件越少的规律越普遍，而"人类对规律普遍程度的认识取决于其变革世界的能力"（能量守恒、元素不变、宇称守恒先后降格为特殊规律）。"人从不把完全可控的客体当作科学研究的对象"——科学以人为中心向外扩展：控制了火→炼铁→工具仪器一圈圈伸向无穷远。

## Key Concepts
- 苯结构三模型迭代：链状→环状→大π键，误差逐步减小=可判定条件成立时的正常逼近。
- 反馈滤波的人肉版：对无关信息"视而不见、听而不闻"。

## Mental Models
- **认识失灵先查五部位**：变量够不够？理论清不清晰？循环快不快？修改过不过头？误差能不能反映对错？
- **把"错"分类**：模型错（改模型）vs 变量缺（换手段）vs 判定失效（找中间标准）——三种"实验失败"的处理完全不同。
- **给自己提清晰性要求**：任何判断若在任何结果下都"不会错"，它就没有信息量。

## Anti-patterns
- 认为"只有打开黑箱才算真正认识"。
- 模棱两可、四平八稳、永不犯错的表述。
- 不更新手段只重复旧循环。
- 按眼前实验事实过度修改理论（普朗克式倒退）。
- 在可判定条件不成立时硬用误差大小定优劣。

## Worked Example
**楚军渡澴水（速度条件的完整案例）**：楚攻宋须渡澴水→先派探子测水深→"水很浅可以涉渡"→探子刚测完，山洪暴发河水猛涨→军队照旧涉渡，淹死数千人。作者判语：楚人失败不在没有实践（测水正是实践），而在"未能及时获知客观情况的变化，并根据这种变化来改变自己的决策"——认识循环的速度跟不上客体变化的速度，调节无效。对照组：炉前化验一两分钟报钢水成分，因为钢水变化快；滞后一步，化验毫无意义。

## Key Takeaways
1. 一切认识都是模型；黑箱一层套一层，打开一层还有一层。
2. 特大系统、打不开的系统、一动就坏的系统，用不打开黑箱方法。
3. 理论必须给出信息量才可检验；永不错=零信息。
4. 认识循环速度≥客体变化速度，否则振荡。
5. 反馈过度与反馈速度不足都会造成"在错误间摇摆"。
6. 可判定条件不成立时，用清醒的中间标准护航，同时警惕它替代最终标准。
7. 规律=变量间约束；规律普遍性随人类控制能力扩展而重排。

# 附录：关于12个乒乓球问题（沈学宁、陈宗泽，书页 206–214）

**题面**：无砝码天平，称 3 次，从 12 只球中找出唯一次品（不知偏重还是偏轻）。

**解法一·逻辑推理法**：1–4 vs 5–8。平衡→次品在 9–12，用 3 正品称 9/10/11 三分支收尾。不平衡（设左轻右重）→1–4 可能轻、5–8 可能重；第二次左盘放 1,2,3,5 右盘放 3 正品+4，按平/同向/反向三分支收尾。可靠但"不能举一反三"。

**解法二·控制论方法（一般化）**：
1. 建模：可能性空间 M=12×2=24（哪只球×轻重），目标 mA=1。
2. 可行性公式：M/Q ≤ mA，Q=工具选择能力。天平一次 3 种结果→Q=3，三次 Q=3³=27>24→**可解**（14 球 28>27→不可解）。
3. 求最优分组：设一次称 a+b 只、留 c 只（a+b+c=n），平均选择率 P̄=1/(4n²)·[2(a+b)²+4c²]，求极值得 **c=n/3 时 P̄ 极小=1/3**——即每次均匀三分、把可能性空间压缩到 1/3，天平最大选择能力为 3。
4. 具体称法解方程组：第一次称 x=8 只、留 y=4 只（满足 2y/9≤1、x/9≤1、x+y=12）；第二次按"在 y 中"或"在 x 中"分别再均匀三分。
5. 方法论启示：①"能不能做到"先算 M 与 Q 再设计；②优化=每次均匀三分；③"举一反三"源于方法的一般性（13 只可解、14 只不可解可由同一公式直接判定）。

## Connects To
- **Ch1**: 附录是控制能力公式 M/m 的完整实战；可判定条件失效=负反馈退化为随机控制（蒙眼鹰抓兔）。
- **Ch4**: 稳态思想支撑"错误稳态"与"振荡"两种认识失灵形态。
