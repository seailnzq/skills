# Chapter 1: 控制和反馈（书页 1–33）

## Core Idea
一切控制行为的共同底座是"可能性空间"：事物有多种发展可能，控制就是在其中做有方向的选择；而控制能力不足时，用负反馈把有限能力累积起来。

## Frameworks Introduced
- **可能性空间**：事物发展变化中面临的各种可能性集合，"控制论中最基本的概念"。事物并非从一开始就注定发展成现在这样（L型/D型氨基酸、生命之树）。
  - 控制的两个前提：①对象必须存在多种发展可能性（只有一种可能＝无所谓控制，如光速）；②人能通过一定手段在可能性中做选择（无法选择＝无法控制，如火山爆发）。
  - 展开方式："歧路之中，又有歧焉"（《列子》歧路亡羊）——可能性空间随事物演变逐级分岔。
- **控制的三个基本环节**：①了解事物面临的可能性空间是什么；②在其中选择某些状态为目标；③控制条件，使事物向既定目标转化。（例：治病——可能性空间=好转/恶化/死亡，目标=好转，控制条件促转化。）
- **控制能力 = M/m**：实行控制前后的可能性空间之比。M 为控制前的可能性空间，m 为控制后缩小的空间。"可能性空间缩得越小，标志着我们的控制能力越强。"多数控制只需缩到一定范围，不必缩到惟一状态。
- **随机控制（探索/寻找）**：碰运气也是科学方法。特点：可能性空间**只有达到目标值时才缩小**，未命中不缩小（神农尝百草、米勒实验、逐把试钥匙）。适用：对对象一无所知时往往惟一可用。
- **有记忆的控制**：凡被证明不是目标的状态，从下一轮可能性空间中排除（翻抽屉找信）。空间逐次缩小，选择次数上限 ≈ log₂N。陷阱：千万别记错——把目标误否定并记住，目标从此出局。
- **共轭控制 L⁻¹AL**：先施行变换 L 把不可控对象变为可控对象，施行可控过程 A，再施行逆变换 L⁻¹ 变回来。"它并不涉及某一具体的工具的发明，但却包含了一切工具的控制原理。"自动化中 L 称感受器、L⁻¹ 称效应器。
- **负反馈调节**：本质是"设计了一个目标差不断减少的过程"。两个必备环节：①系统一旦出现目标差，自动出现减少目标差的反应；②减少目标差的调节一次一次发挥作用，**对目标的逼近能积累起来**。只满足①的是半反馈调节（保险丝、安全阀），不如负反馈完备精确。
- **负反馈放大控制能力**：连续逼近的总控制能力 = (A/B)·(B/C)·…·(x/m) = A/m，每段都大于 1，故 A/m 远大于单次——有限控制能力被累积起来。"用通常的话来说，负反馈调节就是'做起来看'。"
- **正反馈（正反馈耦合）**：一系统偏离目标后，另一系统的反应使其**下一次更加偏离**——目标差不断增大，互为因果越推越远（军备竞赛、对诗"盲人骑瞎马"、心脾两虚恶性循环、爆炸）。注意：正负反馈可互相转化；对系统结构演化正反馈极为重要，不可一概当坏事。

## Key Concepts
- **不确定性**：事物的矛盾性使可能性空间至少有肯定自身与否定自身两种状态；承认它区别于经典决定论（矛可能戳穿盾也可能戳不穿）。
- **目标差**：实际状态与目标的差距，负反馈的调节对象。
- **选择与控制的关系**："控制，归根结底是一个在事物可能性空间中进行有方向的选择的过程。"人造纤维=选择原料+温度+压力+催化剂的条件组合。

## Mental Models
- **把"能不能控制"拆成两个问题**：有没有多种可能？有没有选择手段？两个都答"是"才谈得上控制。
- **把"能不能做到"变成算术**：所需控制能力 vs 工具能力之积，超了则任何操作技巧都无用。
- **把控制不足转化为时间问题**：一次做不到→分段做、逐次逼近，让能力沿反馈链相乘。

## Anti-patterns
- **惟一状态偏执（小圆圈捕鸟）**：看到"最后卡住鸟的是一个网眼"就造一个小圈捕鸟。所需控制能力超过工具能力时，"无论我们怎样改变操作方法，都不会达到控制目的"。
- **探索范围估计不足（竹竿进城）**：竖着不行横着不行，忘了"直着顺城门送出去"——目标根本不在探索范围内，再试也白搭。
- **常识偏见压缩探索空间（拉瓦尔蒸汽轮机）**："轴越硬越好"的偏见让他漏掉了软轴——有弹性的软轴高速转动中反而自然保持平衡。
- **记忆控制中记错**：碰到目标没认清就否定并记住，目标永久出局。
- **忽视陷阱与顺序**：可能削弱控制能力的不可逆状态（如致命药物、"死"）不应最先尝试；选择顺序会影响后续选择余地（沉淀吸附带走小含量离子）。
- **把话说死、否认不确定性**：自相矛盾的商人。
- **只靠事先周密安排而不敢"做起来看"**：仅靠发射时瞄准，永远打不到月球。

## Worked Example
**曹冲称象 = 一次教科书式的 L⁻¹AL**。直接称象办不到（没有能称大象的秤），但称石头可以（A=称重）。曹冲的三步：①L——把大象引上船，刻下吃水线，换成石块直到船沉到同一吃水线（把"象重"变换成等价可称的"石重"）；②A——分批称出石头总重；③L⁻¹——石头总重即象重。凡是"把不能做的变成能做的"都套这个模子：固体粉末混匀（L=溶于液体，A=搅拌溶液，L⁻¹=蒸干）、杠杆、人机控制生产（感受器→人选择→效应器）、乃至数字与语言的起源（把动物变换成小石头计数）。

## Key Takeaways
1. 动手控制前先画可能性空间：有哪些可能？哪些可被选择？
2. 控制目标定"范围"而非"惟一状态"；所需控制能力超过工具能力之积就改方案，别硬操作。
3. 一无所知时用随机控制，但必须保证目标在探索范围内——先怀疑"探索范围是否被常识偏见压缩"。
4. 逐次排除（有记忆）远快于盲目重复；避开不可逆陷阱、安排好选择顺序。
5. 做不到的事，找 L⁻¹AL：找个变换把问题搬进你能控制的范围。
6. 大目标、弱能力→上负反馈：小步逼近、逐次积累，"做起来看"。
7. 警惕正反馈恶性循环（越偏越远），也别把正反馈一概当坏事——它是演化的引擎。
