# 速查表（cheatsheet）—— 金观涛式决策卡

## 一句话总纲
> 一切控制 = 在可能性空间中做有方向的选择；一切认识 = 可能性空间的缩小；一切组织 = 联系方式的确定性。

## 可行性判定（动手前 30 秒）

| 情形 | 判定 | 动作 |
|---|---|---|
| 对象只有一种可能 | 无法控制 | 放弃"控制"表述（光速） |
| 有多种可能但无选择手段 | 无法控制 | 先发明手段，否则别承诺（火山） |
| 所需控制能力 M/m > 工具能力之积 | 必然失败 | 改方案/换工具/分段逼近，别怪操作 |
| 目标不在探索范围内 | 白搭 | 先扩大/重估可能性空间 |
| 存在不可逆陷阱状态 | 高危 | 陷阱状态永不最先尝试 |

## 方式选择（当 X 则 Y）

- **单次做不到** → 找 L⁻¹AL：变换 L 搬进可控域 → 干 → 逆变换搬回。
- **大目标弱能力** → 负反馈："做起来看"，逐次积累，总能力=各段之积。
- **信息不足** → 先攒信息量再控制（纪昌学箭：先练眼力）。
- **传不出信息** → 查通道三因素：操作速度 / 可辨状态数 / 对接受者的控制力；容量≈信息量。
- **信息可疑** → 按干扰选滤波：随机→重传；系统→异通道互证（环节必须不同）；频率→阻抗；主观→情调；持续杂音→反馈；间歇混入→同步。事件越重大，独立通道越多。
- **判断概率** → 条件概率分解 D/A=(D/B)(B/C)(C/A)，别信直觉（井水枯→地震 <1%）。
- **分析整体** → 圈相对孤立系统：剪掉概率小的远因，闭合成互为因果，按时间尺度取变量。
- **预测系统** → 找稳态结构，稳定者即归宿；省略中间步骤。
- **要系统自组织** → 五条件：组织核心、亚稳定母体、自动选择链、不可逆敬畏、核心容差。
- **防崩溃** → 找临界值、找自动增长链、找坏掉的负反馈；压制到临界下即安全（反应堆 <1.007）。
- **要翻转系统** → 新质增强且旧质不同步减弱=飞跃（备好动荡）；同步削弱旧质=渐变（绕开折叠区）。
- **翻转后想拉回** → 飞跃翻转+在关节区=要矫枉过正（反向力度远超正向）；否则勿过正。
- **判断飞跃/渐变** → 只看中间过渡态稳不稳定，不看速度（酸碱滴定=渐变；多米诺=飞跃）。

## 认识失灵五部位排查（反复实践仍错时）

1. **变量限制**：可观察/可控制变量不够 → 换手段，重复实验无用（柳树实验）。
2. **清晰性**：理论给不出信息量（怎么都不会错）→ 零价值，先改成可证伪表述。
3. **速度**：认识循环 < 客体变化 → 振荡，先提速（果蝇代豌豆）。
4. **反馈过度**：每次修改都过头 → 减小步长。
5. **可判定条件**：误差不再反映对错 → 别硬比误差，启用清醒的中间标准，警惕普朗克式倒退。

## 危险信号（tells & smells）

- "把话说死"= 否认不确定性（矛与盾商人）。
- "仪器/流程越精密越好" = 可能单位时间信息通过量反降。
- 只动一个变量就下结论的互为因果系统 = 开巴鹿悲剧预定。
- 永远正确、四平八稳的表述 = 零信息量。
- 越来越偏、互相加码的循环 = 正反馈恶性循环（也可能是演化引擎——先辨场合）。
- 仪表太稳/流程太稳 = 牺牲了灵敏性。
- 长期"实践-修改"却在原地打转 = 五部位之一失灵，停下排查。

## 关键数字与公式

- 信息量 = −log₂(缩小比例)，比特；可加总。
- 控制能力 = M/m；N 次独立尝试 = (单次能力)ᴺ。
- 天平上限：单次选择能力 3；n 球称 k 次 → 可辨 3ᵏ；12 球（24 空间）3 次可解，14 球（28）不可解；最优分组 c=n/3。
- 突变模型：条件变量 ≤4 → 仅 7 种基本突变；>5 → 无限多种。
- 三个变量限制判据：特大系统 / 打不开 / 打开即毁 → 必用不打开黑箱法。
