# 术语表（glossary）

**半反馈调节** — 只满足"出现目标差自动出现减差反应"、不满足"逐次积累"的调节机制，如保险丝、安全阀；不如负反馈完备精确 (Ch1)

**不可逆性（自组织）** — 自组织过程一旦形成某种组织，再改成别种组织形式就很困难；生物进化不走回头路 (Ch3)

**不可判定（可判定条件不成立）** — 实践与理论的误差不再反映理论与真理的接近程度；此时误差大小不能用来修改模型 (Ch5)

**不稳/亚稳定（自组织前提）** — 自组织系统的母体必须是不稳定或亚稳定的（如过饱和溶液），过于稳定则组织过程无法自动进行 (Ch3)

**残余信息 / 信息量守恒** — 信息在传输中只会减少不会增加；环节越多干扰越多 (Ch2)

**超稳定系统** — 靠不稳定来维持稳定的系统：失稳时启动修复机制回到原有稳态；周期性地稳定—不稳定—稳定 (Ch3)

**存储三特点** — B 比 A 稳定；B 只反映 A 的一个侧面；须知道 L_AB 与 L_BC 对应关系才能取用 (Ch2)

**打开黑箱 / 不打开黑箱** — 两种认识方法：直接观察控制内部结构 vs 从输入输出关系推理内部结构；打开一层还有一层 (Ch5)

**单值区/双值区/三值区** — 蝴蝶型突变中控制平面上一质态、两质态共存、三质态共存的区域；三值区被干扰掩盖后收缩为三相点 (Ch4)

**分叉与汇流** — 演化两模式：孤立系统旧稳态破坏后面临多个新稳态（分叉）；原先孤立后建立联系的系统走向共同稳态（汇流）(Ch3)

**负反馈调节** — 设计一个目标差不断减少的过程；两环节：出现目标差自动减差 + 减差作用逐次积累 (Ch1)

**共轭控制 L⁻¹AL** — 变换 L 把不可控变为可控，施行可控过程 A，再逆变换回来；一切工具的控制原理 (Ch1)

**关节点** — 飞跃发生的临界点；不是固定的点，而是随条件变化有规律分布的区域（尖点阴影区）(Ch4)

**黑箱 / 模型** — 尚有不可观察不可控制变量的客体；根据黑箱外输入输出对内部情况提出的假定称为模型 (Ch5)

**极端共存** — 大系统各子系统同时处于不同质态（水三相点、达尔文群岛昆虫）；仅在关节点分布区域内发生，共存质态间不连续 (Ch4)

**竞争性抑制** — 自组织核心"以假乱真"劫持过程：药物分子长得像正常原料，细菌无法区分而停止繁殖 (Ch3)

**均值（均匀）与稳定** — 均匀=空间位置交换中的不变量，故均匀是稳定态；但生命与社会靠不均匀有序结构（负熵）维持稳定 (Ch3)

**可控变量 / 可观察变量** — 主体对客体的作用反映在输入中；客体对主体的作用反映在输出中 (Ch5)

**控制** — "归根结底是一个在事物可能性空间中进行有方向的选择的过程"；三环节：了解可能性空间→选目标→控制条件 (Ch1)

**控制能力 M/m** — 实行控制前后可能性空间之比；所需控制能力超过工具能力之积则任务不可完成 (Ch1)

**概率因果** — 因果联系带偶然性；相关概率小到一定程度即视为无关 (Ch3)

**可能性空间** — 事物发展变化面临的各种可能性集合；控制论最基本的概念 (Ch1)

**滤波** — 对抗信息传递中干扰的技术与认识论课题；七法：重复传递、异通道对比、信息量守恒（近源）、阻抗、情调、反馈、同步 (Ch2)

**内稳定器（homeostat）** — 艾什比设计的模拟超稳定系统的机器；小偏移互反馈拉回，大偏移拖动其他子系统直至寻得稳态 (Ch3)

**偶然因果链（自动增长链）** — 自繁殖与自组织内部"结果本身成为原因"的因果链 (Ch3)

**偏差目标差** — 实际状态与目标的差距；负反馈的调节对象 (Ch1, Ch5)

**平衡态 vs 稳定态** — 两曲线交点都是平衡态，但只有受干扰能自动回归的才是稳定态 (Ch3)

**齐次性（势函数奇偶次）** — 偶次势函数（尖点、蝴蝶）质态可逆、可经条件选择飞跃或渐变；奇次（折线、燕尾）含不可逆稳定态 (Ch4)

**清晰性** — 理论要给出一定信息量才能被实践检验；与波普尔可证伪性一致；"明天可能下雨也可能不下雨"=零信息 (Ch5)

**三相点** — 水的固液气三态共存点；蝴蝶型三值区在大量干扰下的收缩点 (Ch4)

**时间** — 反馈调节速度必须大于客体变化速度，否则振荡（楚军渡水、电风扇周期）(Ch5)

**势函数的洼** — 稳定机制的数学表达：洼底=稳定态，洼越深越稳定；洼移浅=渐变，旧洼消失=突变 (Ch4)

**随机控制** — 可能性空间只有达到目标值时才缩小的探索方式；前提是目标必须在探索范围内 (Ch1)

**通道容量** — 通道单位时间可传递的最大信息量；应约等于要传递的信息量 (Ch2)

**突变理论** — 托姆 1972：条件变量<4 时突变只有 7 种基本方式；本质是揭示质变方式如何依赖条件变化 (Ch4)

**稳态结构** — 互为因果系统中各子系统都处于稳定态所形成的整体不变结构；可用于预言复杂系统归宿 (Ch3)

**稳态结构的预言** — 稳定的结构就是事物最可能的归宿；可省略中间步骤（油田、月球一面朝地球）(Ch3)

**相对孤立系统** — "系统并不是指一个客观存在的实体，而是人们的一种规定"；按目的与时间尺度圈定互为因果变量组 (Ch3)

**信息** — 可能性空间缩小过程的传递；信息量=缩小比例的负对数（比特）(Ch2)

**信息的主观性** — 同一信息对不同接受者意义不同（华容道的烟）；不可把头脑加工过的信息当客观事件 (Ch2)

**选择率（控制率）P=1/Q** — 天平问题的优化量；均匀三分（c=n/3）时平均选择率最小=选择能力最大 (附录)

**有记忆的控制** — 被证明非目标的状态从下一轮可能性空间中排除；陷阱：误把目标否定并记住 (Ch1)

**浴流、振荡（认识）** — 反馈过度或速度不足使认识在两个极端间摇摆（微粒说—波动说之争）(Ch5)

**自繁殖** — "某变量值越大，变量值增加越快"的链式反应系统；存在临界值；常因负反馈机制破坏而爆发 (Ch3)

**自组织系统** — 无需外部干预、在一组事物间自动发生的组织过程；五特点：组织核心、亚稳定母体、自动选择链、不可逆、差之毫厘失之千里 (Ch3)

**智力放大** — 智力=单位时间正确选择的能力；放大=把大范围选择化为小范围选择（选对人/选对工具/选对组织核心）(Ch3)

**中间标准 / 范式** — 可判定条件不成立时使用的辅助鉴别标准（真理统一性信念等）；不是最终标准而是中间路标 (Ch5)

**组织（信息的视角）** — 事物间联系方式的 possibility 空间从大变小；组织程度与信息量度量一致 (Ch2)。组织=联系方式的确定性
