# jin-guantao-cybernetics

Agent skill generated from 《控制论与科学方法论》（金观涛、华国凡著，新星出版社 2005）with [book-to-skill](https://github.com/virgiliojr94/book-to-skill)。

提炼全书方法论骨架：可能性空间、控制能力 M/m、共轭控制 L⁻¹AL、负反馈、信息量与滤波七法、相对孤立系统、稳态结构、超稳定系统、自组织、突变理论（飞跃/渐变判据、势函数洼、关节点、滞后、极端共存）、黑箱认识论（认识失灵五部位排查）。含 18 个可执行模式与一页决策卡。

**Install**：本技能托管于私有技能仓库 [seailnzq/skills](https://github.com/seailnzq/skills) 的 `jin-guantao-cybernetics/` 子目录（与仓库内其他个人技能一致）。安装：克隆 skills 仓库后把本目录复制到宿主的技能目录即可。
