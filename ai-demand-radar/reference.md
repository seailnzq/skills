**A 层综合判读规则**
- A1 在 2026H2 已撞测量天花板（16h），**不能再用"时长不再增长"推导"技术停滞"**。
- 替代主判据改为 A2 + A3：新任务类别是否继续出现、单位成本是否继续腰斩。
- A6 是**需求扩散的路径图**：数字劳动 4 个月翻倍，物理世界 20 个月。意味着未来 2 年算力需求仍主要来自"替代屏幕前的人"，不是"替代产线上的人"。

**B 层判读规则**
- B1 已过 50%，**S 曲线斜率最大点在 50%，之后增速必然下移**。这不是需求转弱，是数学。
- 因此 B 层不再承担"加速"判据，权重让给 C3。
- B2 的尾部行业（建筑 42%、零售 49%）是**扩散是否见顶的先行指标**：尾部加速=扩散还在扩；尾部停滞=只剩头部存量。

**C 层判读规则（最重要）**
- **二阶导的驱动力在 2026 年发生了换挡**：从"更多 agent 数量"切到"单个 agent 更长的任务链"。前者有天花板（企业数×岗位数），后者没有明显上限（任务复杂度）。
- 这解释了为什么 IDC 说 token CAGR >3500% 而成本 CAGR 仅 ~260%——量在指数增长、单价在指数下降，**总支出增速被夹在中间**。
- C5 必须配对 E4（利用率）读：价涨可能是供给被 HBM 卡住，不是需求强。

#### 组合加权弹性（每次必算）

**① 用估算系数（初版，2026-11-02 前）：**
```
弹性 = Σ(持仓权重 × 传导系数)
     = 0.29×0.30 + 0.27×0.60 + 0.24×0.70 + 0.10×0.50 + 0.08×0.30 + 0.015×0.80 + 0.001×0.20
     = 0.087 + 0.162 + 0.168 + 0.050 + 0.024 + 0.012 + 0.0002
     ≈ 0.50
```

**② 用 2026Q3 实测系数的校准值（当前有效）：**
```
弹性 = 0.29×0.55 + 0.27×0.40 + 0.24×0.60 + 0.10×0.10 + 0.08×0.23 + 0.015×1.00 + 0.001×0.50
     = 0.160 + 0.108 + 0.144 + 0.010 + 0.023 + 0.015 + 0.001
     ≈ 0.46
（翱捷 0.23 = ASIC 系数 1.80 × ASIC 收入占比 13%）
```

**③ 实测反算（最硬的口径）：**
```
组合 Q3 营收加权同比 = 43.20%（含长鑫 +600%）
                     = 34.20%（剔除长鑫）
需求代理 = 云厂 2026 capex 同比 +77%
实测弹性 = 43.20 / 77 = 0.56 ｜ 34.20 / 77 = 0.44
```
三个口径（0.46 / 0.50 / 0.44～0.56）互相咬合，**系数体系成立，但结构错了**——见下。

**解读**：AI 需求每增 10%，组合收入增约 4.6–5%；加权时滞约 2 个季度。
**剩下 50% 去哪了**——三个漏损点，每次必须逐一检查：
1. **份额漏损**：需求转成国产了，但没转到你这家（海光 3%，华为 28%）
2. **产能漏损**：订单有了，产能放不出（中芯被 DUV 锁、长鑫 HBM 良率 25%、盛合被 TSV 转接板锁）
3. **价格漏损**：量增价跌（token 单价年降 60–70%；盛科 Q3 毛利率同比 -10.85pct 是硬证据）

**新增第 4 个漏损：二次产能漏损。** 设备环节（E8）不只受晶圆厂扩产约束，还受**自身零部件供应**约束。北方华创 Q3 同比仅 +1.31%（合同负债 +23.54%、存货 339 亿），公司口径为「个别品类物料供应紧张」。设备厂缺件 → 交付不出 → 晶圆厂扩产慢 → 整条链的产能漏损被放大一层。**设备不是「最灵敏的先行指标」，是被二次卡住的一环。**

#### 单位权重弹性（2026-11-02 新增，用于识别仓位错配）

```
单位权重弹性 = 该标的营收同比 ÷ 该标的权重
```

| 标的 | 权重 | Q3 同比 | 单位权重弹性 |
|---|---|---|---|
| 长鑫存储 | 1.5% | +600%（③级估） | **400x** |
| 翱捷科技 | 8% | +38.76%（ASIC 分部 +948%） | 4.85x |
| 盛科通信 | 24% | +44.24% | 1.84x |
| 海光信息 | 29% | +45.46% | 1.57x |
| 中芯国际 | 27% | +29.92%（Q3E） | 1.11x |
| 盛合晶微 | 10% | **-8.33%** | **-0.83x** |

**当前错配**：弹性最高的资产仓位 1.5%，弹性为负的资产仓位 10%。
**但必须加一条刹车**：长鑫的 400x 是 DRAM 周期涨价驱动，涨价斜率已在收敛（Q2 +80% → Q3 +13~40% → Q4 +10~15%），1–2 季内衰减。**用周期弹性做仓位决策是错的**；这一栏只用来识别「仓位与传导方向是否同向」，不用来排序加仓。

#### 环间横向传导（2026-11-02 新增，原矩阵只有纵向）

十环原设计是单向往下的（需求 → 各环），实跑发现**环与环之间还有横向挤压**，必须显式建模：

| 边 | 方向 | 机制 | 强度 | 时滞 | 实证 |
|---|---|---|---|---|---|
| E5 → E11 | **负** | DRAM 涨价 → 端侧合封成本↑ → 终端涨价 → 需求收缩 | -0.30③ | 1 季 | 恒玄 Q3 营收 **-20.03%**、净利 -77.42%，公司明确归因「上游存储芯片涨价，下游客户订单收缩」；瑞芯微同因 PCB/存储涨价致订单顺延，Q3 环比 -6.02% |
| E3 → E11 | 负 | 代工涨价 + 产能被 AI 挤占 → 消费/面板驱动类芯片拿不到产能 | -0.15③ | 1–2 季 | 中芯管理层：「手机、面板驱动类芯片拿不到产能，会逐步涨价」 |
| E5 → E2/E4 | 正 | HBM/DRAM 缺 → 加速架构采用近存/存算一体 → 定制 ASIC 需求↑ | +0.20③ | 2 季 | 翱捷承接「不止一个基于 3DDRAM 架构适配的云端算力 ASIC 项目」 |
| E6 → E10 | 正 | 交换容量升级 → 整机 BOM 价值量↑ | +0.25③ | 同步 | 工业富联 800G 以上交换机出货 +80% YoY |

**用法**：算完纵向弹性后，必须再过一遍横向边。若某环纵向在涨、横向被打，净效应要打折；反之亦然。

**这个 0.46 是可证伪的**：若组合加权收入增速连续 2 季显著偏离「AI 需求增速 × 0.46」，说明系数错，必须用回归重估。当前实测 0.44（剔除长鑫）与之吻合，暂不改。

#### 系数校准方法（季度做一次）

用 2024Q1–2026Q3 共 11 个季度，对每个环节做单变量回归：
```
该环节季度收入同比  =  α + β × 云厂 capex 同比
```
- β 即系数，11 个样本够跑一次粗估，但置信区间会宽，**只作方向校准，不作精确值**。
- 若 β 的符号与表内估算相反（例如某环节需求涨而收入跌），优先怀疑该环节的"份额/产能/价格"漏损，而不是改系数。
- 时滞用互相关（cross-correlation）找最大相关对应的滞后阶数。

#### 传导时滞的实测背书

2026 年那轮见顶顺序：**光模块 6/18 → AI 芯片 6/30 → 代工/CPU 7/10**，三档相差约 2 周。
排序与表内时滞一致：E9（同步，最先）→ E2（2–3 季）→ E3（1–2 季，但由于产能锁定而滞后更久）。
这是唯一一次实测的次序验证，可作系数校准的锚。**注意：这是推断的因果，不是直接证据**——时间相关性成立，但"因为对海外 capex 暴露度不同所以先后见顶"是逻辑推断，标②级。

#### 卡点判定（每次必做的一句话）

> 逐环问：这一环的观测指标在改善吗？如果改善，钱进了谁的账？

- 若 E0 总量在涨、E2 份额不动 → 替代红利被华为/平头哥吃掉，不是你的
- 若 E3 稼动率满、ASP 涨、但片数不增 → 产能墙，收入靠涨价不靠放量
- 若 E4 订单满、收入不增 → 客户验证周期或物料卡（盛合 2026H1 就是样本）
- 若 E6 大客户订单签了、收入没到 → 从签订到确认 2–3 季，别按签订日算

#### 合规缺口专题：2026-11-09 不是「到期日」（2026-11-02 修正）

|---|---|---|
| 美方政治承诺 | 休战延长（2026-09-24 贝森特宣布） | 至 **2027-01-10** |
| 美方规范文本 | Affiliates Rule 暂停规则（90 FR 50857）**未修订** | 至 **2026-11-09**，11-10 自动恢复 |

关键事实：
- 白宫 2026-09-25 事实清单**未提及** Affiliates Rule，只笼统说「关税和非关税措施」
- 商务部 9-28 解读同样未点名 50% 穿透规则（唯一明确点名的是 5-20 解读）

**结论**：政治层面已延期，法律文本双双停在 11/10。这是**合规缺口**，不是「到期恢复」。情形概率（③级，律师分析）：如约展期 ~80%、技术性空窗数日 ~15%、谈判反复 ~5%。

## 三、DT 计算样例（2026-11 实算）

以中国日均 token 为例（C2b）：

| 时点 | 值（万亿/日） | 同比 g | DT = ln2/ln(1+g) |
|---|---|---|---|
| 2025-01 | 1.6 | — | — |
| 2025-12 | 9.6 | 500%（vs 2025-01） | 0.39 月 |
| 2026-03 | 140 | 1358%（vs 2025-03 基数不可比） | — |

**结论：这条序列不可用于 DT 计算。** 原因：①统计口径在 2025 年内发生过跳变（1.6→9.6 是 6 倍，9.6→140 是一个季度 14.6 倍，不合常理）；②基期不可比。

**替代做法**：
- 用 IDC 的年度口径（2026 全年 4 亿亿 token vs 2025 全年约 0.2 亿亿）→ 同比约 20 倍 → DT ≈ 0.23 月，同样不可信。
- **降级处理**：中国 token 只作"方向确认"（在涨、涨得很快），不作 DT 计算。DT 只用在美国侧有连续同口径序列的指标（B1、C5、D2）。
- 这是一条重要教训：**不是所有指标都能算二阶导，口径不连续的只能定性。**

可算 DT 的指标（口径连续）：
- B1 企业采用率（月度连续，券商固定口径）
- C5 GPU 租赁指数（周度连续）
- D2 云厂 capex（季度连续）
- A1b 任务时长（METR 统一方法，但已饱和）
