## 一、叙事滑动词典

| 滑动词 | 泄露的叙事 | 修正语言 |
|---|---|---|
| 硬抗 | 对抗性 + 体力消耗 + 被动挨打感，预设"有一天会被耗尽"；从"我选过的路"滑到"命运给我的考验" | 持有 / 不动 / 等 |
| 熬 / 挺 / 撑 | 悲壮叙事——最消耗心力、最不利于长期持有的版本 | 按纪律执行 |
| 崩了 / 完了 / 不行了 | 全局合成：数据不足时大脑把多事件打包成"整体不行" | 拆回单件，一码归一码 |
| "我应该心静" | 把心静当第四项 KPI，遇乱后叠加"我怎么又乱了"的自我审判 | 心静不是没有波动，是波动来时还认得自己的尺子 |
| 回到本金就体面 / 市场欠我一个反弹 | 成本锚：市场不知道用户的成本，成本对价格无因果影响 | 止损参考在产业事实层，不在账户金额 |
| 黎明前的黑暗 / 路径正确 | 不可证伪尺子的两面解释（涨也对跌也对） | 换成可核查阈值（见第三节） |

**冷语言的判定标准**：可执行、可证伪、无形容词。悲壮语言的判定标准：预设消耗、预设考验、无动作项。

### 层 1 / 层 2 分离方法

- **层 1 = 理性层**：用户书面写过的框架——时间轴、红线、纪律、角色定位、判定项。
- **层 2 = 默认层**：未经审查的社会化预期——"这个阶段应该""别人家的孩子""同龄人比较""作为父亲应该管""这个年纪不该这样"。
- **检验句**："这条预期，是我写进框架的，还是它自己在运行？"
- **后果**：层 2 不识别会污染层 1 执行——以为在"等他自己长出来"，实际每天用微表情微语气传"我很不满意"。
- **判据缺失**：框架没写红线/判定项时，任何数据点都能触发焦虑。补法：时间锚 + 2-3 条判定项 + "短期结果不在这几条里"的显式排除。

## 二、回撤 ABC 分类：定义与历史案例

### A 类｜产业活着 + 估值/流动性/周期三件套

- 板块 -50% ~ -80%；三件套（估值消化 + 流动性收缩 + 周期下行）每 3-5 年出现一次。
- **不影响终局，不需要锚。**
- 历史案例（方向性对照，不追小数点）：
  - 费城半导体 SOX 2000-2002：-83%（互联网泡沫）。产业后来一路长大，2010 创新高。
  - 费城半导体 SOX 2008：-72%（金融危机 + 流动性冲击）。2009 见底后一路涨。
  - 申万半导体 2018：-50% 以上（熊市 + 去杠杆 + 全球存储周期见顶）。2019-2021 走出 100%+ 牛市。
  - 中证半导体 2021.7 → 2022.10：约 -50% ~ -60%（消费电子周期下行 + 加息预期 + 估值消化）。2023 AI 起来后板块翻倍。
- **关键论据**：-50% ~ -80% 的顶底回撤，绝大多数**不需要产业证伪作为前提**。

### B 类｜产业部分证伪

- 触发示例：HBM 国产化率到目标年仍 < 30% / 先进制程被新制裁锁死 / AI capex 长周期低于预期。
- 板块 -60% ~ -90%；个股 -80% ~ -95%；十年二十年一遇。
- 原"12-24 个月主链收入普遍不兑现"式红线锚的就是 B 类——**这条锚是对的**，因为部分证伪发生时它能被产业事实识别出来。

### C 类｜产业彻底证伪

- 触发示例：技术路线整体走错 / 国产链条被证明是国家级资金错配。
- 历史参考：日本半导体 1990s 后半段被韩国 + 美国挤压。
- 此时不是回撤问题，是**个股归零**问题；讨论金额无意义。
- 概率比 B 类低一个数量级，日常不用管，心里要知道它存在。

## 三、beta 校准与金额锚定

### 隐含 beta 算法

```
隐含 beta = 组合区间回撤% ÷ 同期板块指数区间回撤%
```

- 区间必须**同一起止日期**；组合取峰值对当前，指数取同期峰值对同期当前。
- 示例：组合 430w → 265w = -38.4%；同期半导体指数约 -30% → beta ≈ 1.28。
- 满仓 5-7 只同链个股（算力主链五层同涨同跌，下游于同一条 capex + 政策周期）时，A 类情形下个股 beta 通常 > 1.2。集中度的代价。
- 缺指数数据：让用户提供，或配合 a-stock-realtime 技能取数。

### 金额锚定模板

输入：峰值 P、隐含 β。

| 类 | 计算 | 含义 |
|---|---|---|
| A 类上界 | P × (1 − 0.50~0.60) × β | 指数 -50%~60% 传导到组合的合理上界 |
| B 类尾部 | P × (1 − 0.70~0.85) | 部分证伪的尾部带，通常低于 A 类上界 |
| C 类 | 不适用 | 归零讨论 |

- 用户的盈亏线 / 成本线**不是**锚；"极限情况"要用同类组合的历史经验分布去锚。
- 输出格式：`A 类上界 = X ~ Y；B 类尾部 = Z ~ W（从峰值 P 起算，beta 取 β）`。
- 收尾动作：请用户对 B 类尾部显式确认"能扛"。确认后写下："能扛 = 看清边界之后的选择；硬扛 = 不敢看边界的姿势。"

## 四、-50%/尾部场景预演三段式

书面预演，三段：

1. **现金流结构**：那个时点家庭必需支出 / 收入稳定性 / "5 年内不动用"是否仍成立。
2. **产业认知**：那个时点用第 3 步的产业阈值逐条对照，**不用账户金额对照**——金额不携带产业信息。
3. **动作清单**：那个时点我做什么、不做什么。写下来。

目的：不是确认"能扛 X 万"，是确认"叙事能不能撑住"。没做过预演的硬抗，是把预演留给未来恐慌时点做的、不可信任的判断。

## 五、产业事实阈值示例库（数值占位，用户自定）

| 维度 | 示例格式 |
|---|---|
| HBM | 国产 HBM 国产化率到 {{年份}} ≥ X% |
| 制程 | 7nm 及以下国产制程月产能 ≥ Y wafers/月（注意 8 寸折算口径） |
| 份额 | 国产 AI 芯片在国内服务器/数据中心份额 ≥ Z% |
| 生态 | 国产生态（CANN/MUSA 等）开发者数量达到 NVIDIA CUDA 的 W% |
| 收入 | 12-24 个月主链公司收入普遍兑现（原红线，锚 B 类） |

要求：每条 = 指标 + 数值 + 时间点；写入执行层记录页时只写阈值与时间点，不写金额。

## 六、钱 vs 产业的时间差（分诊"痛的性质"）

- 资金面信号（两融余额及降幅、融资活跃度历史分位）用于分诊，不是卖出信号。
- 产业可能继续兑现、股价可能继续跌——中间这段**资金退潮期**就是正在承受的东西；它不改变终局，只改变到达终局的账面曲线形状。
- 分诊结论二选一：痛来自"产业判断错了"（→ 走红线/阈值判定），或痛来自"流动性收缩"（→ 不需要自我怀疑，看第 1 步的触发判定即可）。分不清的人，会在最不该动的时候动。
