# 持仓回撤叙事审计

对回撤期的情绪扰动做四步审计：把叙事与事实拆开、把滑动的语言修回冷语言、把不可证伪的尺子换成产业事实阈值、把"最坏能亏到哪"从心理锚改为分布锚。**全程不改变任何买卖决策，只校准叙事与边界。**

## 定位

**适用**：回撤期心神不宁 / "如何自处" / 对抗性悲观语言 / 尺子含糊或不可证伪 / 多领域扰动打包成"全局不行"。

**不适用**：实时行情与分时量能（用 a-stock-realtime）；季报产能良率核查（用 fab-capacity-five-ring-audit）；解禁日历（用 a-share-unlock-calendar）；控制论概念查询（用 jin-guantao-cybernetics）。

## 总原则（贯穿四步，违反任何一条即重来）

1. **不改决策，只改叙事与边界。** 审计产出的是"看清边界之后的选择"，不是操作建议。
2. **先要事实，再审计。** 没有事实层时拒绝审计，先做第 0 步追问。
3. **纪律语言是冷的，不是悲壮的。** 可执行、可证伪、无形容词。
4. **能失败，才能真的赢。** 不可证伪的尺子是心静最隐蔽的敌人。
5. **盈亏线不是底，是心理锚。** 市场不知道用户的成本，成本对未来价格无因果影响。
6. **"能扛"与"硬扛"的区别**：前者是看清边界之后的选择，后者是不敢看边界的姿势。
7. **不替用户定阈值数值**，只给 X/Y/Z/W 占位与方向；数值必须用户自己定。

## 流水线

### 第 0 步｜分诊

- **确认领域**：投资 / 学业 / 工作 / 其他。多领域并发扰动（"最近什么都不顺"）时，每件一纸，不合并、不起名"最近状态"。
- **缺事实层则先追问四项**：时间（何时开始，有无具体日期/事件）、事件（具体类别）、数字（可量化就给一个数，拒绝"少了很多"）、实际参与度（直接负责/被分派/仅观察——三类责任度完全不同）。参考句式：一句话，只有数、时间、结构，不带形容词。
- **禁词自查**：事实层不得出现"状态不好 / 崩 / 完了 / 不行 / 我担心 / 这样下去"——这些是叙事和情绪，不是事实。
- **情绪元层**：若用户叠加"我怎么又乱了"的自我审判，先指出"我应该心静"本身成了新的执着——遇事起浪不是水坏了；此刻坐下来要求审计本身就是修心的证据，只是没给自己记这笔账。

### 第 1 步｜三张纸四行审计

按此结构填，每纸一行一行过：

1. **① 原始事实**：一句话，不带形容词。只有数、时间、结构。
2. **② 原来的尺子**：逐项复述用户原框架——时间轴 / 产业轴 / 红线 / 卖出触发 / 纪律——请用户确认复述是否准确。尺子从未包含的项目（如"这次回撤应该小于 X%"）当场指出。
3. **③ 触发判定**：逐条对照，明确"哪条触发、哪条没触发"。不可证伪的条目标注"暂不给判定"，转入第 3 步；无法确认的纪律项（杠杆/必需资金）请用户显式确认一次。
4. **④ 不用管 / 要审的分界**：没触发的部分默认不用管；真正需要审的点（通常不超过两个）留在④里，交给第 2-4 步处理。

### 第 2 步｜叙事语言滑动检测

扫描用户原话中的滑动标记（词典详见 [reference.md](reference.md)）：

- **对抗性悲壮词**：硬抗 / 扛 / 熬 / 挺 / 撑 / 顶住——带对抗性、体力消耗性、被动挨打感，预设"有一天会被耗尽"。叙事已从"我在走我选过的路"滑到"我在承受命运给我的考验"。修正为冷语言：**持有 / 不动 / 等 / 按纪律执行**。这一改不改变任何决策，只改变能不能撑完持有期。
- **全局合成叙事**："我最近不行 / 我的判断整体错了 / 路径有系统性问题"——多事件同时发生时大脑的合成产物，不是事实。拆回单件，一码归一码。
- **层 1 / 层 2 分离**：层 1 = 用户书面写过的理性框架（时间轴、红线、纪律、角色定位）；层 2 = 未经审查的社会化默认预期（"应该""别人都""这个阶段该"）。心神不宁常来自层 2 被冒犯而非层 1 被触发。检验句："这条预期，是我写进框架的，还是它自己在运行？"层 2 不识别会污染层 1 执行。
- **成本锚语言**："回到本金就体面 / 市场欠我一个反弹"——市场不知道用户的成本。

### 第 3 步｜终局尺子可证伪化

- **检测不可证伪项**：尺子中出现"全面超越 / 市场主流已经认可 / 标准主导"类表述即命中。"市场主流认可"是**共识信号**（估值层的燃料），不是**产业信号**——共识最易反转，用它回答产业问题，意味着尺子可以给任何走势做解释（涨是路径正确，跌是黎明前的黑暗）。
- **替换为产业事实阈值**：1-4 个可核查项，每条 = 指标 + 阈值 X% + 时间点。示例库见 [reference.md](reference.md)（国产化率 / 月产能 / 份额 / 生态）。**能被证伪，才能被宣告完成。**
- **红线分层**：A 类情形不需要锚（不影响终局）；B 类锚在产业事实上（部分证伪时可识别，如"12-24 个月主链收入普遍不兑现"）；C 类无对应触发项，概率低一个数量级，日常不管，但心里要知道存在。
- **落地要求**：阈值写入用户的执行层记录页（如 wiki-life 投资记录页），只写阈值与时间点，不写金额。

### 第 4 步｜回撤 ABC 分类 + beta 校准 + 极限锚定

**ABC 分类**（完整定义与历史案例见 [reference.md](reference.md)）：

| 类 | 情形 | 板块幅度 | 频率 | 框架对应 |
|---|---|---|---|---|
| A | 产业活着 + 估值/流动性/周期三件套 | -50% ~ -80% | 3-5 年一遇 | 不需要锚，不影响终局 |
| B | 产业部分证伪 | -60% ~ -90%（个股 -80% ~ -95%） | 十年二十年一遇 | 红线锚在这里（产业事实可识别） |
| C | 产业彻底证伪 | 个股归零 | 历史罕见 | 无触发项，知道存在即可 |

**beta 校准**：隐含 beta = 组合区间回撤% ÷ 同期板块指数区间回撤%（同一起止日期，峰值对峰值）。满仓 5-7 只同链个股时 beta 通常 > 1.2。需要指数数据时配合 a-stock-realtime 或让用户提供。

**金额锚定**（输入：峰值 P、隐含 β）：

- **A 类上界** = P × (1 − 指数回撤 50%~60%) × β
- **B 类尾部** = P × (1 − 70%~85%)
- **C 类**：不适用——"跌到哪里"不再是问题，"哪里是零"才是。

输出两行金额区间，然后要求用户对 **B 类尾部**显式确认"能扛"——确认成立后，当前位置的每个决策才是从从容容做的。

**预演三段式**（模板见 [reference.md](reference.md)）：让用户书面预演尾部场景——①现金流结构 ②产业认知对照第 3 步阈值 ③做什么、不做什么。目的不是确认"能扛 X 万"，是确认"叙事能不能撑住"。

## 输出格式（固定，按序）

1. **四行纸结论**：①事实 ②尺子 ③触发判定 ④不用管/要审分界。
2. **反诘段落**：先说过关项（明确记这笔账），再审点一/二/三，每点给出修正动作。
3. **ABC 分类表**：三类情形 → 组合金额区间（含 beta 换算过程）。
4. **下一步**：只选一件，标注"今天做 / 本周做 / 本周末做"。零成本动作优先（如划掉一个词）。

## 完成检查

- [ ] 每张纸都有四行，事实层无形容词
- [ ] 滑动词已替换为冷语言（原词与新词都写明）
- [ ] 不可证伪尺子已换成带时间点的阈值，数值由用户自定
- [ ] ABC 三类的组合金额区间已算出（beta 换算过程可见）
- [ ] 用户对 B 类尾部做了显式"能扛"确认（或明确说"下次确认"）
- [ ] 下一步只有一件
- [ ] 全程未给出任何买卖决策
