# 多线四纸拆解 · 领域审点话术与检查清单

本文件是 SKILL.md 第 2 步（领域专用审点）与第 3 步（合纸收口）的执行细节。按需查阅，不必整篇读入。

---

## 一、四项事实追问模板（第 0 步通用）

对任何缺事实层的线，按此句式追问：

- **时间**：什么时候开始的？有没有一个具体事件 / 具体日期？
- **事件**：具体是哪一类？（给用户类别菜单，见下方各线清单）
- **数字**：如果可量化，给一个数。**不要给"少了很多""影响收入"这种。**
- **实际参与度**：你直接负责的？被分派协助的？还是你观察到但没参与的？三类对应完全不同的责任度。

参考句式：*"一句话，只有数、时间、结构，不带形容词。"* 事实层写的时候，情绪先靠边站。

**禁词清单**（事实层出现即要求重写）：状态不好 / 不用功 / 崩 / 完了 / 不行 / 我担心 / 他这样下去 / 少了很多。

## 二、投资纸审点（摘要级；深水区转 portfolio-drawdown-narrative-audit）

### 审点 A｜叙事语言校准
- 滑动标记：**硬抗 / 扛 / 熬 / 挺 / 撑 / 顶住**——对抗性、体力消耗性、被动挨打感，预设"有一天会被耗尽"。
- 修正为冷语言：**持有 / 不动 / 等 / 按纪律执行**。话术：*"这一改不改变任何决策，只改变你能不能撑完持有期。纪律语言是冷的，不是悲壮的。"*

### 审点 B｜终局尺子证伪化
- 识别不可证伪条目："全面超越""市场主流已经认可"（共识 ≠ 产业事实，共识是最容易反转的东西）。
- 改造方向（数值用户自定，只给占位）：国产 HBM 国产化率 ≥ X%；先进制程月产能达 Y wafers；国产 AI 芯片国内份额 ≥ Z%；国产 CUDA 生态开发者达对标 W%。
- 话术：*"能被证伪，才能被宣告完成。永远不能被满足的宏大叙事，是心静最隐蔽的敌人。能失败，才能真的赢。"*

### 审点 C｜回撤分类与 beta 校准（一句话版）
- **A 类**：产业活着 + 估值/流动性/周期三件套 → 板块 -50%~-80%，当前回撤多在此带内，不影响终局。
- **B 类**：产业部分证伪 → 板块 -60%~-90%、个股 -80%~-95%，用户红线应锚此类。
- **C 类**：产业彻底证伪 → 罕见，讨论回撤无意义，是归零问题。
- 满仓集中组合隐含 beta > 1.2：指数跌幅 × beta 才是个股组合的实际路径。用用户已实现的回撤 / 同期指数回撤反推 beta。

### 审点 D｜极限金额锚定
- 盈亏线是心理锚不是底；"能亏到盈亏线"≠"能亏到底"。
- 让用户预演真正极限（A 类上界再往下）：① 那个时点家庭现金流结构；② 那个时点产业认知有无变化；③ 那个时点做什么、不做什么。
- 话术：*"'能扛'和'硬扛'的区别：前者是看清边界之后的选择，后者是不敢看边界的姿势。"*

## 三、子女纸审点

### 审点一｜目标是谁的目标
- 检验问题：**"X 名 / X 校"是孩子独立表达过（他说要考，你去查了位次），还是你先在心里定了、再"分享"给他的？**
- 前者 = "我的孩子有一个他要追的东西"；后者 = "父亲要我从 Y 爬回 X"。孩子对"父亲的目标"只有两种心理回应：逆反、或表面配合但内在放弃（完成作业但不投入内驱力——作业没问题是他能交付的最低成本）。
- 附加检验：目标学校恰好是父亲母校时，明确问用户"这个事实会不会给他带来压力"——答案是"会"，不是因为孩子脆弱，而是目标一旦是父亲的目标就自带压力。
- 后续沟通检验点：**能不能真的接受"不一样"的答案**。孩子最后说的还是那所学校，很好；不是，你能不能稳住——这才是沟通的真正检验。

### 审点二｜角色过渡：管理者 vs 同行者
- 框架：15 岁前父亲主要是管理者；15-18 岁要过渡到同行者（不给答案，只示范与陪伴）。**过渡阵痛最常见的形态，就是父亲自己的心神不宁**——想用 12 岁的方式处理 15 岁的问题。
- 判定用户当前在哪条赛道：管控动作（禁手机 / 配额 / 检查）= 管理者；等待与陪伴 = 同行者。**动作和心智不一致 = 能量在内耗里掉光**。
- 三条路，只许选前两条之一：
  1. **明着做管理者 + 明确退出时间**：一句话说清楚——"这一次爸爸替你着急，想帮你顶一把，我知道这可能不是你想要的，X 月考完我就退回来。"管理者动作 + 明确退出时间 = 可修复。
  2. **退回同行者**：管控在下一个节点前解除，把节奏还给孩子。
  3. **禁止第三条**：悄悄管、嘴上说不管——消耗最大、修复最难，孩子读得出来，自己心里也过不去。
- 若用户原框架是"心法→自摸→生成、不代打"，则指出管控动作与框架错位：外部约束能拉短期名次，**拉不出"他自己的方法论"这类长期判定项**。两者都是可选策略，但不能混着用。

### 审点三｜"没有抵触 ≠ 内部认同"
- 孩子对管控"没有抵触"有两种：真接受消化了；评估过反抗成本太高、选择不反抗。**外部观察看不出差别。**
- 独立评估项：**他主动说了什么**——有没有在某次聊天里自己主动谈到手机、娱乐、自己最近的状态。没有 = 手上证据只有"行为合规"，没有"内部认同"。
- 配套动作：一周一次的沟通里，挑一次**不谈考试、不谈作业、不谈管控**，聊一件孩子主动投入的事。这不是沟通技巧，是**角色信号**：爸爸可以只是爸爸，不必是教练。"只在考试后出现"是裁判，不是队友。

### 审点四｜红线三判定项（无红线时给出方向，阈值用户自定）
- **判定项 1**：孩子是否已形成**他自己的**一套学习方法（他能讲给别人听的，不是你给的）。
- **判定项 2**：孩子是否保有**主动做一件事**的习惯（学习之外也行——运动、动手、游戏，只要是他主动投入的）。
- **判定项 3**：孩子是否愿意在遇到困惑时**主动来找你**（肯问就行，不必倾诉）。
- 三条都在 = 路径成立；任一缺失 = 方法证伪、需调整。**短期成绩不在这三条里**——把它从红线剔除，就是给焦虑一个边界。没有红线的自由，是焦虑的温床。

## 四、工作纸审点：容器 vs 事件四问

工作纸常见形态：用户只给形容词（"不顺利""影响收入"），无数、无事件、无参与度——**信息密度差本身就是第一个数据点**（两种解释：实际权重低 / 事实未浮出，让用户自选）。

### 问一｜奥卡姆：容器还是事件？
- 检验：**"如果投资、孩子、家里都在预期，工作还会是问题吗？"** 答案"不会" = 工作是投资 + 教育焦虑溢出后的**第三个容器**，是症状不是事件。42 岁身上最容易承接"我最近不行"这个叙事的靶子就是工作。
- 判定为容器后话术：**"这张纸是空的——这是你自己说出来的，不是我替你判的。"**

### 问二｜逆向：有没有具体动作？
- 如果工作真的"不顺利"到心神不宁的等级，手上应该有具体动作（找主管谈项目、争取新线、内部转岗、接触外部机会、复盘某类投标）。
- **一个都没有 = 用户自己心里已经判定它不到那个等级。心神不宁是情绪，不是判断。用情绪当尺子，会把小事量成大事。**

### 问三｜降维：两个"不会"
- ① 今年会不会被裁？② 现金流会不会断？
- 两个"不会" = 工作完整履行了它在人生规划里"求稳 / 现金流支撑"的使命。**它从来不是提供成就感或身份确认的场——那是层 2 的旧叙事在偷偷要求它做它不该做的事。**

### 问四｜算数：把感觉折成钱
- "影响收入"背后有一个没问出口的问题：**今年预期多少？实际差多少？算过没有？**
- 算法：`差额 = 预期收入 − 实际收入`；再算两个比：`差额 / 总仓位`、`差额 / 投资浮亏`。
- 典型结论形态：差额是总仓位的 1%-2%、浮亏的 2%-3%、**投资一天波动就能吞掉**——**为这件事分配的情绪权重远大于它在实际生活里的权重，这是焦虑的认知错配。识别到它，它就散了。**
- 话术：*"算出来的'少了 X 万'和算不出来的'少了很多'，对情绪的作用差 5 倍。感觉不能当决策输入。"*
- 责任归属分检：部门业绩 vs 个人职责——"我该做的都在做"时要帮用户把**行业水位下降**（单子变少、周期变长、预算收缩）与**个人能力下降**分开：前者不需要自我怀疑，后者才需要。

## 五、合纸收口话术（第 3 步）

- **"同时"才是痛源**：三处（或多处）不完美没有一处独立致命，但它们**同时从峰值回落**，让 20 岁设计的整体路径叙事第一次出现裂缝。裂缝才是真正的痛，不是任何单线。
- **约束条件核对**（逐条问）：现金流结构？杠杆？纪律（必需资金 / 退出时间）？家庭基本面？——通常结论：**约束条件一条没紧，紧的是叙事。**
- 回用用户自己的话（如"叙事是供给过剩的那一个，钱才是约束条件"）——用用户已固化的语言收口，比引入新概念有力。
- 整体尺子改造：**"我要一路顺利" → "我知道路径会有波动，我盯的还是那个终局。"** 换完之后，最轻的那张纸自己就轻了。
- 可选落地：建议用户把这条整体叙事写进自己的记录（只写路径形状，不写金额）——写完会发现两件事：① 它比任何单线都古老；② 它被检验的这一刻，恰是可以换一条更长叙事的时候。

## 六、收束话术（第 4 步）

- 指出剩余处理已不在认知层："你今晚要处理的已经不是认知层的事。识别到的东西已经够了。"
- 最小动作菜单（**任选一件就够**）：和配偶说一句话（不谈投资、不谈孩子，就一句话）/ 给父母打 5 分钟电话（只聊日常，不谈自己近况）/ 今晚早睡。
- 宣布停止：**"今天的动作到这儿为止。不再开新分析。"**
- 收尾意象（可用可不用）："心静"不是把 5 条线全部拆完，是**认得**它们各自的位置、允许它们在各自的时段浮上来。已拆干净的线在原地待着，不用你处理。水不需要一直清澈，浊的时候让它自己沉。
