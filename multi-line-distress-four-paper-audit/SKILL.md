# 多线心神不宁四纸拆解审计

用户报告投资、子女教育、工作（以及配偶、父母这两条背景线）**同时不顺利、心神不宁**时，用本流水线把"全局不行"的合成叙事拆回一张一张的纸，逐纸走四行审计，最后落回一件最小的身体/关系层动作。**全程不改变任何买卖、教育、职业决策，只校准叙事、边界与角色。**

## 定位

**适用**：多线同时扰动打包成"最近什么都不顺" / "整体叙事出现裂缝"的痛感 / 各线事实密度悬殊 / 分不清哪条线真正冒头。

**不适用**：
- 投资单张纸的深度回撤审计（语言滑动、尺子证伪化、ABC 分类、beta 校准的完整版）→ 用 **portfolio-drawdown-narrative-audit**；本技能投资纸只做该技能的编排入口与摘要级执行。
- 实时行情与分时量能 → 用 a-stock-realtime。
- 控制论概念查询 → 用 jin-guantao-cybernetics。

**姊妹技能分工**：`portfolio-drawdown-narrative-audit` = 投资单纸的深水区；本技能 = 多线编排 + 子女纸 + 工作纸 + 收口与收束。投资纸遇到深水问题（回撤分类、beta、极限锚定做不完）时，明确请用户转投姊妹技能，不要在本技能里硬塞。

## 总原则（违反任何一条即重来）

1. **不改决策，只改叙事、边界与角色。** 审计产出"看清边界之后的选择"，不是操作建议。
2. **先要事实，再审计。** 任何一张纸没有事实层就拒绝审计，回到第 0 步追问。
3. **一次只拆真正冒头的线。** 五线并列不等于五线全拆；用户没点的线不主动拉出来审。
4. **纪律语言是冷的，不是悲壮的。** 可执行、可证伪、无形容词。
5. **能失败，才能真的赢。** 不可证伪的尺子（"全面超越""应该顺利"）必须转成可核查阈值。
6. **不安源默认在层 2。** 层 1 = 用户书面写过的理性框架；层 2 = 未经审查的社会化默认预期。心神不宁通常是层 2 被冒犯，不是层 1 被触发。
7. **不替用户定阈值数值**，只给 X/Y/Z/W 占位与方向。
8. **收口即收工。** 第 4 步之后不再开新分析、不追加审计点。

## 流水线

### 第 0 步｜五线分诊

用户说"多线不顺"时，先并列摆出五条线：**投资 / 子女 / 工作 / 配偶 / 父母**。

- **识别真正冒头的线**（通常是 2 条，最多 3 条）：用户主动给过细节的、反复回到的、带情绪词的线。配偶、父母两条多数时候是背景噪声——用户大致知道它们没崩。**背景线点名即可，不拆**。
- **每条冒头的线追问四项事实**（缺哪项问哪项）：时间（何时开始，有无具体日期/事件）、事件（具体类别）、数字（可量化就给一个数，拒绝"少了很多""影响收入"这类）、实际参与度（直接负责 / 被分派协助 / 仅观察）。
- **事实层禁词自查**："状态不好 / 崩 / 完了 / 不行 / 我担心 / 这样下去"——出现即要求重写。参考句式：一句话，只有数、时间、结构，不带形容词。
- **信息密度差本身是数据点**：各线给的事实密度悬殊时（如投资给了 4 个数、工作只给了形容词），向用户指出两种解释并让其自选——① 该线在实际不安里的权重比自以为的低；② 该线事实层还没浮出水面。两种解释对应完全不同的处置（前者少审、后者先追问）。
- **情绪元层**：若用户叠加"我怎么又乱了"的自我审判，先指出"我应该心静"本身成了新的执着——遇事起浪不是水坏了；此刻坐下来要求拆解本身就是修心的证据，只是没给自己记这笔账。

### 第 1 步｜逐纸四行审计（顺序：投资 → 子女 → 工作）

每张纸按四行走，一行一行过：

1. **① 原始事实**：一句话，不带形容词。只有数、时间、结构。
2. **② 原来的尺子**：逐项复述用户原框架（时间轴 / 判定轴 / 红线 / 纪律 / 角色定位），请用户确认复述是否准确。**尺子里从未包含的项目**（如"这次月考应该进 X 名""回撤应该小于 X%"）当场指出——那是层 2 偷偷塞进来的。
3. **③ 触发判定**：逐条对照，明确"哪条触发、哪条没触发"。不可证伪的条目标注"暂不给判定"，转第 2 步证伪化；无法确认的纪律项（杠杆 / 必需资金 / 管控退出时间）请用户显式确认一次。
4. **④ 不安源定位**：没触发尺子的部分默认不用管；真正的不安源做层 1 / 层 2 分离——检验句："这条预期，是我写进框架的，还是它自己在运行？"结论通常写成：**不安来自层 2 社会化预期被冒犯，不是层 1 框架被触发**。层 2 不识别会污染层 1 执行（详见 reference.md 领域审点）。

### 第 2 步｜领域专用审点（每纸通常不超过 2 个审点）

审点话术与检查清单详见 [reference.md](reference.md)，此处只列骨架：

- **投资纸**：语言校准（"硬抗"→"能扛 / 持有 / 等"）；终局尺子证伪化（共识叙事 → 产业事实阈值）；A/B/C 回撤分类 + 个股隐含 beta 校准；极限金额锚定（盈亏线是心理锚不是底）。深水区转 portfolio-drawdown-narrative-audit。
- **子女纸**：目标归属（"前 50"是孩子独立表达的，还是父亲先定再分享的？）；角色过渡（15-18 岁管理者 → 同行者，过渡阵痛的常见形态就是父亲的心神不宁）；**"没有抵触 ≠ 内部认同"**——外部观察看不出真接受和"反抗成本太高所以不反抗"的差别，独立评估项是**他主动说了什么**，不是行为合不合规；红线三判定项（他自己的方法 / 主动投入的事 / 愿意来找你）。
- **工作纸**：**容器 vs 事件四问**——① 奥卡姆：如果其他线都在预期，工作还是问题吗？（不是 = 容器/症状，不是事件）；② 逆向：有没有任何一个具体动作在推进？（没有 = 用户自己心里已判定它不到这个等级，情绪不是判断）；③ 降维：被裁吗？现金流断吗？（两个"不会" = "求稳"使命已完整履行）；④ 算数：把"少了很多"折算成具体金额，再除以投资浮亏或总仓位得出百分比——**认知错配一旦算出来就散了**。

### 第 3 步｜合纸收口

所有冒头的纸拆完后合起来看一次：

- **多线同时从峰值回落，"同时"本身才是痛源**——不是任何单线独立致命，而是 20 岁前后设计的那条整体路径（读书→好大学→头部厂→稳收入→孩子同一所高中→投资跑赢→50 岁上台阶）第一次同时出现多处不完美，**整体叙事出现裂缝**。
- **约束条件核对**：逐条核对用户的硬约束（现金流、杠杆、纪律、家庭基本面）——通常**一条都没紧，紧的是叙事**。用用户自己的话回给他（如"叙事是供给过剩的那一个，钱才是约束条件"）。
- **宏大终局尺子证伪化**：如果整体叙事里藏着不可证伪的条目（"全面超越""一路顺利"），给 1-2 个可核查项改造方向（如 HBM 国产化率 > X%、先进制程 wpm 达同代节点 Y%、组合极限亏损分布锚），数值用户自定。**"我要一路顺利"可换成"我知道路径会有波动，我盯的还是那个终局"。**

### 第 4 步｜收束（一次只做一件，然后停）

- 指出今晚剩余的处理已不在认知层，在身体与关系层。**任选一件最小动作**：和配偶说一句话（不谈投资、不谈孩子，就一句话）/ 给父母打个 5 分钟电话（只聊日常）/ 今晚早睡。
- **明确宣布：不再开新分析。** "心静"不是把五条线全部拆完，是认得它们各自的位置、允许它们在各自的时段浮上来。已拆干净的线在原地待着，不用再处理。

## 与姊妹技能的分工表

| 场景 | 用哪个 |
|---|---|
| 只有投资一条线扰动 | portfolio-drawdown-narrative-audit |
| 投资+子女/工作等多线同时扰动 | 本技能（投资纸深水区可转出） |
| 实时行情/分时量能 | a-stock-realtime |
| 收口后用户想继续追投资纸细节 | 转 portfolio-drawdown-narrative-audit，不并入本技能 |

## 验证

- 五线都盘点过、冒头线不超过 3 条、背景线只点名未拆解。
- 每张冒头的纸四行齐全，①无形容词，③有逐条触发判定，④明确写出层 1 / 层 2 分离结论。
- 至少一处使用"没有抵触 ≠ 内部认同"或"容器 vs 事件"判据（若对应线冒头）。
- 收口处完成了约束条件核对并指出"紧的是叙事"。
- 以一件最小身体/关系层动作收束，且未开启新分析线。
