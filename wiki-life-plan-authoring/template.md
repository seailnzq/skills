# 主文档（方向层）骨架

```markdown
# <起年>-<止年> 人生规划

## 一、终局视角
以库内锚点（如 9000 天 / 预期健康寿命）为界，用一两段说清"这盘棋下到什么时候、要的是什么"。引用 [[framework/第一性原理]]、[[framework/人生阶段与目标]]。

## 二、阶段划分（触发器，不是日历）
| 阶段 | 年段/年龄 | 核心命题 | 进入/退出触发器 | 本阶段关键死法 |
|------|----------|---------|----------------|---------------|
| 冲刺 |  |  | 若 <X> 则启动 <Y> |  |
| 过渡 |  |  |  |  |
| 自主 |  |  |  |  |
| 收尾 |  |  |  |  |
（每阶段再分心+认知/身/关系/价值/时间/工作/投资逐条给方向，用 [[elements/...]] 回链）

## 三、五要素速览表
| 要素 | 阶段1 | 阶段2 | 阶段3 | 阶段4 |

## 四、财务与触发判据（方向层只给结论）
- 达标判据用**覆盖倍数 ≥ N**（分母取实际带宽中值，口径见附录 §X），不用名义总额自我认证。跨期数字一律折现到同一口径（名义 vs 实际）再比较。
- 高方差项（教育、父母照护等）按**低/中/高三档**给区间并注明触发条件，不写单点值；只有低方差项允许单点。
- **不可逆窗口**动作（如商业保险可保期、政策试点资格）给明确 deadline 并进 §六近期衔接表；可逆动作标低优先级。
- 关键缓冲/带宽结论一句话给出，推导放附录。

## 五、失败清单（逆向思维）
主动列"绝不想发生"的路径：健康死法 / 意义死法 / 关系死法 / 财务死法……每条是可检查的信号。

## 六、关系对齐与近期衔接
- 双人决策的对齐时间点与议程顺序（第一议程写清楚）。
- 近期动作表：主线下挂 [[execution/...]] 具体页。

## 七、待确认事实
本轮仍缺、会影响判断的事实（核不到的列这里，别在正文假装知道）。
```

# 附录（论证层）骨架

```markdown
# 规划附录：<主题>（通胀 · 财务测算 · 保险精析 · 政策与尾部风险）

## 一、通胀与财务测算
- 名义 vs 实际口径分列；给规划锚（如综合 2%、医疗照护分项 5–8% 单列）。
- A/B 方案带宽推导；覆盖倍数分母取值。**每个数字与 execution 对齐，注明"已按 vX 下修/上调 + 原因"。**

## 二、保险配置精析
- 现有保单盘点（含价格对比现价）、可保性窗口、优先级顺序、机制依据。

## 三、政策 / 时效事实
- 长护险、医保、地方补贴（如加装电梯门槛/表决/造价）——每条标"截至 YYYY-MM 公开资料"，附 WebSearch/WebFetch 来源。

## 四、经验与尾部风险论证
- 支撑方向层结论的反面证据与情景。

## 五、口径联动备忘
- 列出会在主文档多处出现的数字，改一处要同步的点（配合 Grep）。
```

> 用法提醒：方向层被新事实推翻时，**先改附录论证、再回改主文档结论**，保证"结论永远有依据"。两文件用 §编号互指。
