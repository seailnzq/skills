# 财报净利 Bridge 拆解（高研发公司版）

当报表利润被股权支付（SBC）扭曲时，净利增速 ≠ 经营真实增速。本 skill 提供一套可复用的拆解流程，回答"为什么扣股份支付后净利增速 > 收入增速？"以及"净利率变化由哪些因素贡献？"

## 触发场景

- 净利润增速明显高于/低于收入增速，需要归因
- 公司披露了"扣除股份支付影响后的净利润"（科创板常见，A股报告第一节"主要会计数据"第九项）
- 毛利率下降但净利率提升，直觉矛盾
- 研发费用率"看起来没降"但经营杠杆似乎存在
- 对比多家同类公司（GPU/AI芯片）的盈利质量

## 核心洞察（先记住这几条）

1. **股份支付是纸面费用、不付现金**，且常被新推的激励计划集中计提（授予时点决定峰值）。剔除后还原真实经营利润率。
2. **研发费用是股份支付的"藏身处"**：海光 6.34 亿 SBC 中 5.41 亿（85%）在研发费用。所以"研发费用率"可能被 SBC 撑高，剔除后研发付现费用率才反映真实投入。
3. **研发人力杠杆是净利率提升的最大来源**：研发人员增速远低于收入增速 → 研发付现费用率下降 → 净利率提升。这是高研发公司进入放量期的核心经营杠杆。
4. **归母增速可能被少数股东损益变化放大**：少数股东损益占比下降 → 归母净利增速 > 整体净利润增速。必须同时看整体净利润增速。
5. **研发资本化率下降 = 藏利润**（更审慎），上升 = 美化利润。变化方向要单独解读。

## 操作步骤

### Step 1：取数（利润表 + 三份附注）

从半年报/年报提取：
- 利润表：营业收入、营业成本、税金及附加、销售/管理/研发/财务费用、其他收益、投资收益、公允价值变动、信用/资产减值、营业外、所得税、净利润、归母净利、少数股东损益（两年同期对比）
- 费用附注（63 销售 / 64 管理 / 65 研发）：各费用里的"股份支付"分项
- 股份支付附注（十五）：本期股份支付费用按对象拆分（销售/管理/研发人员）
- 主要会计数据第九项：扣除股份支付影响后的净利润（两年）
- 现金流量表附注（78）：支付其他与经营活动有关的现金明细（交叉验证费用付现）

### Step 2：算"股份支付税后影响"

```
扣股份支付后归母净利 = 报表归母净利 + 股份支付税前费用 × (1 - 有效所得税率)
```
用公司披露的"扣除股份支付影响后的净利润"直接对比两年。

### Step 3：算净利率变化，并归因（Bridge）

```
净利增速 > 收入增速  ⟺  净利率提升
```
把"扣股份支付后净利率"的变化拆成各因素贡献（占收入比）：
- 毛利率
- 税金及附加率
- 销售/管理/研发费用率（**分别算含 SBC 和不含 SBC 两版**）
- 财务费用率
- 其他收益率、投资收益、减值损失率
- 所得税率
- 少数股东损益率

正向合计 − 负向合计 应约等于净利率变化（±0.5pct 内为正常误差）。

### Step 4：专项检查清单（每个都给出定性结论）

- [ ] **研发付现费用率** = (研发费用 − 研发SBC)/收入。变化幅度是经营杠杆的核心证据
- [ ] **研发人力杠杆**：研发人员增速 vs 收入增速。人员增速 << 收入增速 = 杠杆释放
- [ ] **资本化率变化**：下降=更审慎（藏利润），上升=美化。同时看绝对额
- [ ] **少数股东损益占比**：下降会放大归母增速，需查明原因（增持子公司？亏损子公司结构变化？）
- [ ] **毛利率质量**：下滑是成本（存储/晶圆涨价）还是结构（低毛利产品占比升）还是竞争（降价）？参照 AMD/NV/同行的转嫁能力
- [ ] **"支付其他"科目**：保证金（可回收资金占用）vs 费用付现（研发委外/流片/推广），勾稽验证与利润表费用方向一致
- [ ] **合同负债**：GPU 行业主流"签约→交付→验收→确认→回款"，合同负债天然小，**不是订单指标**。真正前瞻信号 = 存货+预付+应付票据

### Step 5：输出模板

1. 结论先行（净利增速与收入增速背离的定性）
2. 股份支付拆解表（两年对比，分对象）
3. 净利率 Bridge 表（各因素贡献）
4. 三个"放大/隐藏"因素识别
5. 边界与风险（毛利率真实压力、少数股东原因待查等）

## 注意事项

- 有效所得税率要用"扣SBC后净利 − 报表归母净利"反推 SBC 税后影响，不要直接用 6.34×税率（还要考虑可抵扣/加计扣除）
- 研发费用里的股份支付受激励计划授予/等待期节奏影响，跨期对比必须标注授予时点
- 少数股东损益变化必须单独解释，否则归母增速会被误读
- 本方法适用于所有高 SBC 公司，不限于半导体（生物医药、SaaS 同样适用）
