# 参考手册：业绩预告增量分析

本文件承载 SKILL.md 工作流的公式、模板与一个完整示例。按需读取，不必每次全读。

---

## 1. 口径表模板（本次预告）

| 口径 | 本期（累计/区间） | 上年同期 | 同比 |
|---|---|---|---|
| 营业收入 | | | |
| 归母净利润 | | | |
| 扣非归母 | | | |
| 调整后归母（如扣股份支付） | | | |
| 调整后扣非 | | | |

先判定每个数字是**累计口径**还是**单季口径**，还是**区间预告（低—高）**。预告通常给区间，分析时可取中枢（区间均值）做定性，但涉及增速/剪刀差要同时给区间下沿与上沿，避免用中枢掩盖边界风险。

---

## 2. 单季反推与剪刀差公式

设本期为前三季度累计（1–3Q），已披露上半年为 1–2Q：

- 单季 3Q = 累计(1–3Q) − 已披露(1–2Q)，营收与利润各自相减。
- 3Q 同比 = 3Q本期 ÷ 3Q上年同期 − 1（上年同期 = 去年累计 − 去年上半年）。
- 3Q 环比 = 3Q本期 ÷ 2Q本期 − 1。
- 隐含净利率(3Q) = 3Q归母 ÷ 3Q营收，与 1Q、2Q、上半年整体净利率横比，看利润率是往上还是往下。
- 剪刀差 = 营收增速 − 归母增速（或 − 扣非增速），以百分点(pct)表示。
- 剪刀差趋势 = 本期剪刀差 − 上期剪刀差；收敛还是扩大，指向毛利率/费用是否恶化。

示例算式（区间下沿更保守，务必单独看）：
- 若累计营收 142.80–155.80 亿、上半年 90.99 亿 → 3Q营收 ≈ 51.81–64.81 亿。
- 去年同期 3Q 为 40.37 亿 → 3Q 同比 ≈ +28.3%～+60.5%（注意增速较上半年的 +66.5% 明显降档）。

## 3. 表观 vs 调整后拆解

- **表观（reported / headline）**：报表直接写的、未经调整的最终结果（对应"归母净利润""扣非归母"）。
- **调整口径**：剔除某项一次性或非现金因素后重算（常见：股权激励/股份支付、政府补助、资产减值、投资收益）。
- 关键动作：算 `调整口径 − 表观口径 = 该项金额`，再算**该金额的同比增量**。只有当同比增量足够大时，它才可能是剪刀差的主因；否则主因往往在毛利率或其他成本。

示例：前三季度"扣股份支付后归母" 34.5–37.2 亿 vs 表观归母 27.1–29.8 亿，差额≈7.4 亿即前三季度计提的股份支付；若上年同期该项≈7.24 亿，则同比只多约 0.16 亿 → **剪刀差主因不是股权激励，而是毛利率**。这就是拆口径的实际用途。

## 4. 未披露验证项清单（前瞻）

预告通常只证明"收入确认了"，不证明"新一轮订单/现金/利润率"。逐项列出并标注"待季报确认"：

- **合同负债 / 在手订单**：是否见底回升（比"存货金额"更能指示需求拐点）。
- **经营现金流 / 净现比**（经营现金流净额 ÷ 净利润）：利润是否有现金支撑；净现比长期 <30% 是硬伤。
- **存货、预付款项**：占自身收入比、环比方向；备货还是滞销。
- **毛利率**：同比、环比是否延续下行。
- **关联交易 / 大客户集中度**：收入质量与可持续性。
- **费用率**（研发、销售、管理）与股份支付节奏。

写法：`本次预告未披露 X；这是留给季报的最大悬念`，并说明为什么它比被市场强调的科目更有决策价值。

## 5. 同业镜像表模板（统一口径）

先固定"同一累计区间 + 各取自家公告"，再填表。最后一列是本方法论的核心产出：

| 公司 | 环节 | 营收同比 | 归母同比 | 营收−归母剪刀差(pct) | 扣非同比 | 备注/另一口径 |
|---|---|---|---|---|---|---|
| 标的 | | | | | | |
| 同业A | | | | | | |
| 同业B | | | | | | 扭亏→名义无解，看扣非占表观比 |
| 同业C | | | | | | 未发预告→用最新已披露口径注明 |

产出两条归因清单：
- **行业共性**（多家用同一解释成立，常来自产业链涨价、产品结构切换、备货节奏、收入确认时点等）——属系统性分配问题，不是单一公司经营问题。
- **公司独有**（只有标的出现、同业对照组不成立）——这才是要警惕的经营信号（如只有标的毛利率趋势性下行）。

判定纪律：某结论若被当作"行业共性"糊过去，必须先验证多数同业同口径确实同向；孤例不能升格为共性。卖方研报（如大摩的成本假设）可作共性佐证，但要注明是卖方口径。

## 6. 披露动机与市场背景（可选）

自愿性披露时点、当日板块涨跌、回撤幅度、同日是否有组织性的同业集中发利好——用于判断这是"孤立公司行为"还是"板块性信心窗口"。作为背景补充，不与财务事实混列。

---

## 7. 诚实标注规范

- 每个数字后缀来源标记：`公告` / `推算` / `卖方预测` / `未核实`。
- 区间用 `a%~b%`，中枢用 `≈`，方向用 `收敛/扩大/走平/下行`。
- 结尾必留"需提示的两点"：①哪些是本助手推算而非公告原值；②哪些依赖未审数据、以正式季报为准。

## 8. 完整示例（骨架，供对照）

以"某算力芯片公司前三季度预告"为例的成品结构：

1. **口径表**：营收 +50%~64% / 表观归母 +38%~52% / 扣非 +35%~49% / 扣股份支付后归母 +70%~84%。
2. **增量**：①归因措辞质变"政策驱动→市场驱动"（最重要）；②首次量化股份支付≈7.4 亿、同比仅增 0.16 亿；③剪刀差量化：营收中枢≈57% vs 表观归母≈45%，差 12pct，扣非差 15pct，较中报（差约 17pct）略收敛。
3. **表观 vs 调整后**：剪刀差主因是毛利率下行而非股权激励。
4. **单季反推（推算）**：3Q营收同比降档、归母环比 -17%~+6%、隐含净利率回落——落到下沿即环比负增长，为最需审视信号。
5. **未披露验证项**：3Q合同负债与经营现金流均未披露，为最大悬念。
6. **同业镜像**：已发预告公司里，仅标的"营收增速显著跑赢归母增速"；其余利润增速≥营收增速。故问题不能一句"行业共性"带过。共性 4 条（HBM 涨价压毛利、产品结构切换摊薄、高预付高存货锁产能、Q3 收入确认延迟），独有 4 条（毛利率趋势性下行等）才是经营警示。
7. **结论与不确定项**：一句话判断 + 标注推算与待核实项。
